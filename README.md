## 先选你的日常

| 你想怎么生活 | 可以先比较 | 最先确认的条件 |
|---|---|---|
| 海边工作，下班散步或冲浪 | [兰塔岛](guides/asia.md#koh-lanta)、[Florianópolis](guides/americas.md#florianopolis) | 营业季、住房到工位的距离 |
| 美食、老城与步行生活 | [槟城](guides/asia.md#penang)、[Oaxaca City](guides/americas.md#oaxaca) | 街区噪音、房内网络 |
| 自然多一些，日常安静些 | [古晋](guides/asia.md#kuching)、[Ohrid](guides/europe-africa.md#ohrid) | 雨季、办公权限与交通 |
| 欧洲时区，住在海岸附近 | [Las Palmas](guides/europe-africa.md#las-palmas)、[Madeira](guides/europe-africa.md#madeira) | 实际月租、夜间通话工位 |
| 城市文化，周末去户外 | [Sarajevo](guides/europe-africa.md#sarajevo)、[Arequipa](guides/americas.md#arequipa) | 通勤坡度或高原适应，先短住 |
| 冲浪与共居社交 | [Taghazout](guides/europe-africa.md#taghazout) | 已确认的工位，咖啡馆是否允许电脑 |

这些是按生活方式整理的候选，**没有全球排名，也不承诺全城网速**。公寓的一条差线路，足以让一座“网速很快”的城市不适合你的工作。

## 住得起，也要工作得下去

先拿到旅行日期内的住房报价，再加办公费、日常消费和跨境开销。**工位月费不等于生活月预算，共居套餐也未必含午晚餐。** [预算与网络检查](guides/choose-a-base.md)提供一张可填写的比较表。

例如，兰塔岛 KoHub 的工作季是 11 月至次年 4 月；Madeira 的免费工位公布白天开放；Las Palmas 的共享通话间与专用租用条件不同。地点的实际使用条件都放在对应目的地页。

长期工作还要核对自己的护照、工作关系与许可类别。旅游免签、远程工作许可和税务居民是不同问题。[入境与工作](guides/entry-and-work.md)把它们分开列。
