```sh
cd web
npm ci
npm run demo
```

需要 Node.js 24 或更新的兼容版本。演示使用随仓库提供的公开数据，不需要 Notion 账号或模型密钥；AI 接入另行配置。打开 [本地网站](http://127.0.0.1:8787)。
