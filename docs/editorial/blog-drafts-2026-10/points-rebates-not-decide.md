# 积分与返现不主导决策：为优惠改路线贵在哪

这篇适合谁：适合为了凑积分、返现或优惠门槛，改过航班时间、多住过一晚、或者绕路转机的人，尤其是行程本来由工作时间和停留安排决定、优惠只是临时插进来的人。如果每次出行都没有可改的路线，这篇只需要看顺路优惠一节。

先把三类信息分开。事实部分只讲优惠的成立条件：多数优惠要满足指定通道、指定日期或累计金额才兑现，条件不满足，面值就不成立。预算部分的所有数字都标注为示例假设，只演示算法，不代表任何航班、酒店或平台的真实价格与费率。建议部分讲决策顺序：路线先定，优惠后算。涉及停留天数、入境条件和改签规则的部分，本文只教核对方法，发布前需按官方来源复核。

优惠最容易误导人的地方，是它只标出能省下的那一面，不标出为它付出的那一面。省下的金额印在页面上，具体、显眼；付出的部分分散在时间、差价和额外消费里，没有任何一页会替你加总。这篇要做的就是把那一面也算成一笔账，两个数字放在一起，优惠还值不值得改路线，结论通常自己就出来了。

## 优惠有三类隐性成本：时间、改签差价和被迫消费

第一类是时间成本。绕路转机多出的几小时、为了配合优惠时段改到的清早或深夜航班、为了多住一晚错开的工作日，这些时间不会出现在订单金额里，但会占掉到达当天的状态和工作安排。计算时先按小时记下来，再问一句：这几小时如果换成正常路线，本来能用来工作、休息还是赶路。给不出明确用途的时间可以不计价，但占掉整个工作日或到达后半天的时间，不能按零算。

第二类是改签差价和连带支出。为了迁就优惠改动一处，往往连着改动后面几处：航班差价、多出一晚的住宿、多一次往返机场或车站的交通、原定住宿的取消费用。每一项单看都不大，加总时要按同一笔行程一起算，不能只拿优惠面值去比其中最大的一项。改签规则本身以承运方和订票通道当期公布的原文为准，核对时看清可改范围和收费口径再动手，发布前需按官方来源复核。

第三类是被迫消费。为了达到累计门槛多买的东西、为了用掉优惠多点的一餐、多订的一晚房，判断标准只有一条：没有这项优惠，这笔消费会不会发生。不会发生的，按全额计入成本；本来就会发生、只是提前或换了个地方发生的，只计差价，不计全额。这一类最容易被算漏，因为消费本身带来了东西，会让人觉得钱没有白花，但决策口径看的是多花了多少，不是得到了什么。

三类成本的算法用一个示例假设演示，以下数字均为示例假设，不代表真实价格：假设某项优惠的面值为一百个单位，为它改签多付六十个单位，多住一晚多付八十个单位，被迫消费里用不上的部分为五十个单位，三项合计一百九十个单位，还没有计入绕路多花的几小时。账算到这一步，不需要再讨论积分以后能值多少，改路线这件事本身已经比优惠贵。

## 决策顺序先定路线，优惠只在同等选项里做平局裁决

正确的顺序是把优惠放到最后一步。第一步，先按工作与停留定路线：哪几天要按北京时间开会、到达后第二天是否有工作、这座城的停留安排允许住多久。停留天数以目的地官方发布的当期条件为准，自己核对原文，不拿优惠页面的建议行程代替，发布前需按官方来源复核。第二步，在满足第一步的选项里比总价，总价要含交通、住宿和改动可能带来的连带支出，口径一致再比。第三步，只剩两个条件真正同等的选项时，才让积分和返现来裁决选哪个。

平局裁决的意思是，优惠只能改变同等选项之间的排序，不能把一个本来不合格的选项抬进候选。到达时间差半天、工作日被占、要多住一晚的选项，与原选项不是同等选项，这时优惠再大也只是一个更贵的选项打了折。判断是否同等，先比时间与停留，再比总价，最后才比优惠，顺序反过来，结论就会被面值带偏。

选城层面是同一个顺序。先看城市的评分与停留条件是否适合这一段工作和生活，Roamorrow 的默认评分权重里安全、花费、气候、游民氛围、网络和生活条件是选城维度，支付优惠不在其中。城先定下来，住和行再在城内比价，优惠只处理最后的平局。用优惠反过来定去哪座城，等于让面值最小的一个变量决定成本最大的一个决策。

## 里程与积分按能兑现才计价入账，没用掉之前不算省钱

积分和里程在记账时最常见的错误，是在拿到它们的当天就按面值记成一笔收益。这样记，账面上省了钱，实际上那笔钱还没有发生。入账口径接《多币种记账：一个月对一次账的最低科目表》的做法：积分单独列一个科目记数量和到期时间，不与现金科目混记，不提前折算成金额并入当月支出抵扣。

计价只发生在一个时点：实际兑换并抵掉了本来要付的支出时，按抵掉的金额记。兑换了本来不会发生的消费，不计收益，按被迫消费处理；到期未用的，直接清零，不在账上留一个名义余额。用这个口径对账，一个月下来能看出两个数：这个月真正靠积分抵掉的支出有多少，以及为了积分多付的成本有多少，两边一比，比任何面值宣传都清楚。

返现同理，但多一步核对：返现是回到现金账户、可以自由使用的，才在到账时按现金记；只能在指定通道、指定期限内抵扣的，按积分口径处理，到期和限制都写进科目备注。把限制条件和金额记在同一行，月底对账时就不会把受限额度当成可支配的钱重复花一次。

## 例外只有一种：本来就顺路的优惠照拿，不必为省钱放弃

这篇讲的不是拒绝优惠，而是拒绝为优惠改路线。本来就顺路的情况有三种：路线、时间和住宿都不变，只是付款时多选了一个通道；本来就要发生的消费正好达到门槛，不需要追加任何一笔；两个选项在时间、停留和总价上确实同等，优惠让其中一个略便宜。这三种情况下拿优惠没有隐性成本，面值就是净收益，照拿，不必为了证明自己不受优惠影响而放弃。

顺路与否的判断要在改动之前做，不要在改动之后找理由。动手改签、加住或加购之前，先写下原方案，再写下改后方案，逐项对时间、差价和新增消费，对完再决定。为已经改完的行程找补理由，只会让下一次更敢改。判断表不用复杂，四行就够：时间多了几小时、差价多少、新增消费多少、优惠面值多少，前三项合计小于面值，才算真的省。

## 为优惠改路线之前，先过这张核对表

- [ ] 原路线是按工作时间与停留安排定的，不是因为优惠才成立
- [ ] 停留天数与改签规则已按官方或承运方当期原文核对
- [ ] 时间成本已按小时记下，占掉工作日或到达后半天的没有按零算
- [ ] 改签差价、多住一晚、多出的交通等连带支出已全部加总
- [ ] 新增消费已逐笔判断：没有优惠还会不会发生，不会发生的按全额计入
- [ ] 三类隐性成本合计已与优惠面值比较，合计更低才动手改
- [ ] 积分只记数量与到期时间，实际兑换抵掉支出时才计价入账
- [ ] 属于顺路优惠的，路线不变、消费不加，直接拿，不再多算
