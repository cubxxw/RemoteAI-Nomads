# 房租议价的让步项：不降价时可以谈什么

这篇适合谁：适合第一次租月租房、谈判时只会问能不能便宜一点的人，尤其是房东或平台已经明确不降月租，却还想把第一个月的实付和入住风险降下来的人。如果已经签约入住、要谈的是第二个月降价，先看《续租谈判：第二个月想降价，先拿什么去谈》；本篇只管首次签约前，总价谈不动时还能谈什么。

先把三类内容分开。事实部分只讲让步项分别影响哪一笔钱、落在哪一份文件里，不承诺房东一定会同意某一项。假设部分如果出现天数或金额的拆分，只作示例假设，用来说明怎么算，不代表某个城市、某个房东的常见做法。建议部分讲谈判顺序和落文字的方法。涉及合同条款、押金处理和退租通知期的具体口径，本文只教核对方法，发布前需按官方来源复核，签约前也要按当地当期规则和合同原文再确认一次。

月租只是报价的一部分，真正决定实付的是报价加上水电、清洁、押金占用和退租条件，这一点在《查到的月花费为什么对不上：参考值、报价和实付是三回事》里已经拆过：参考值、报价和实付是三回事。房东不肯动月租，不等于整笔交易没有可谈的空间；可谈的往往是那些对房东成本不高、但对租客第一个月现金流和退租风险影响很大的条件。

## 先谈对房东成本低的项：入住时间、清洁安排和水电结算方式排在前面

让步项按对房东的成本从低到高排序，先谈低成本项，成功率和谈判气氛都更好，也避免一上来就把对话推到对方最不愿意让步的地方。

第一类是时间上的小让步：提前几个小时或半天入住、当天晚一点退房、搬家日与起租日错开半天。这类安排如果不影响上一位租客退房和保洁排班，对房东多半只是协调成本，却能让租客省下一次额外住宿或仓促搬运的麻烦，具体写法见后面一节。

第二类是服务安排：入住前做一次基础清洁、入住第一周内处理小维修、窗帘、灯泡、滤芯这类易耗品由谁更换。谈的不是免费升级，而是把原本口头默认的事项写清责任方和完成时间。

第三类是结算方式：水电按表读数结算还是固定包干，如果是包干要写清包含的范围和超出后的计算方式；如果是按用量结算，要写清入住和退房时的读数如何确认、账单由谁提供。这类条款不改变月租数字，却直接决定退房时是否会多出一笔说不清的费用。

第四类才是现金流和风险更大的项：押金分期、押金退还时限、退租通知期和提前退租的处理。它们对房东的资金占用和重新招租风险影响更大，所以放在清单后面谈，并准备好用更长的租期、更早的付款日或更完整的身份与工作材料来交换，而不是只提要求不给对价。

## 押金谈不下总额，就谈分期和退还时限，而且两项都要写进合同

押金总额谈不动时，不要只停在金额上，继续谈两件事：能不能分期交，以及退房后多久退、按什么条件退。

分期要写清三点：第一期在签约时交多少、第二期在什么日期交、未按时交齐时如何处理。只在聊天里说先交一部分，合同里仍写全额一次付清，争议时以合同为准对自己不利，所以分期安排必须回到合同正文或经双方确认的附件里改。

退还时限要写清三点：退房验收在退房后多久内完成，押金在验收后多久内退到哪个账户，哪些扣款需要提供凭证。扣款凭证的要求和入住时预防的办法，《退房时押金被扣：哪些扣款要凭证，哪些在入住时就能预防》已经讲全，本篇只提醒把那一篇的结论变成签约时的具体条款：入住时拍下房屋状态并留时间记录，退房时的读数和验收结果双方各留一份，扣款逐项列明而不是只给一个总数。

通知期同样要落到天数和起算方式：提前多久通知、通知以什么形式送达才算有效、未按期通知时如何处理。不同地点的合同习惯和规则口径不同，本文不给统一天数，签约前按合同原文逐句核对，发布前需按官方来源复核。

## 免租半天或一天的价值在搬家和保洁，不在省下那点租金

如果房东愿意给免租的半天或一天，不要把它只算成少付半天租金。它的实际用处是把搬家、保洁和验收拆到两个时间段里做完：先搬入和检查房屋，发现问题当天提出；或者退房前一天完成搬出，留出时间做清洁和陪同验收。

谈这一项时要把起止时间写到小时：从哪一天几点开始计租、免租时段是否包含水电、免租时段内房屋损坏由谁负责，都要在合同或确认记录里写清。只写赠送一天，入住日和退租日各算一次，最后反而在天数上扯皮。

示例假设：假设起租日定在每月一号，房东同意入住日前一天下午先放行李且不计租，这半天不改变合同总价，但租客可以提前确认热水、网络和门锁是否正常，把问题清单在正式起租前发给房东。这个例子只说明免租时段的用法，不代表房东普遍会提供这类安排。

## 谈成的每一项都要落文字，口头让步在退房时通常对不上

让步谈成不算完成，落到文字才算。《语言不通时怎么处理维修、房东和就医：关键句和翻译工具的准备》里有一条通用原则：重要约定落文字，尤其在语言不通、双方理解容易错位时，口头确认要转成合同条款、附件或双方确认过的书面记录。本篇的让步项全部适用这条原则。

落文字时逐项检查四个要素：事项本身是什么、金额或计算方式是什么、完成或付款的时间是什么、未做到时如何处理。水电上限只写包水电不够，要写包的范围和超出的算法；清洁只写入住前打扫不够，要写由谁做、在入住前何时完成；维修只写有问题找房东不够，要写响应方式和大致时限的确认渠道。

如果房东不愿意改合同正文，可以要求把谈成的事项列成附件或补充确认，并注明与合同具有同等记录作用，同时保存双方确认的过程。具体效力口径本文不下结论，发布前需按官方来源复核；至少在操作层面，附件比聊天截图更完整，聊天记录比口头更可查，三者不要混为一谈。

签约前把报价重新换算成总成本再决定：月租乘以租期，加上水电的预计结算方式、清洁是否另付、押金占用的金额和退还时限、退租通知期带来的最晚离场日期。让步项改变的是这张总账，而不是月租那一个数字。谈之前列清单、谈之后落文字，这两步做完，首次签约的议价才算真正用上。

## 签约前清单：不降价时逐项问，逐项落文字

- [ ] 入住与退房时间：能否提前半天入住或延后半天退房，起止时间是否写到小时
- [ ] 清洁：入住前清洁由谁负责、何时完成，退房清洁是否另收费
- [ ] 水电：包干还是按表结算，范围、读数确认和超额算法是否写清
- [ ] 押金：能否分期，分期日期和未付齐的处理是否进合同
- [ ] 押金退还：验收时限、退款时限、扣款凭证要求是否写明
- [ ] 退租通知期：提前量、送达形式和未按期处理是否逐句核对合同原文
- [ ] 落文字：谈成的每一项是否进合同正文、附件或双方确认的书面记录
- [ ] 总成本：是否已把月租之外的水电、清洁和押金占用并入实付再做决定
