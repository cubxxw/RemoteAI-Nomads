# 与中介打交道：费用名目与合同主体先问清

这篇适合谁：适合通过中介找月租房的人，尤其是第一次在陌生城市经中介签约、分不清中介费和服务费有什么区别、也不确定合同到底是和谁签的人。如果是直接和房东签约或只在平台上订房，本篇只需要看合同主体和付款凭证两节。

先把三类内容分开。事实部分只讲费用名目、合同主体和押金经手人是三个可以分别确认的问题，不给任何城市或机构的费率、比例或统一做法。假设部分出现的基数和退费情形只作示例假设，用来说明提问方法，不代表实际收费标准。建议部分讲签约前逐项问清并留记录的顺序。涉及中介收费规则、合同效力和押金处理的具体口径，本文只教核对方法，发布前需按官方来源复核，签约前按当地当期规则和合同原文再确认。

很多人把找中介理解成一件事，其实至少有三件独立的事：为介绍房源和带看服务付的钱付给谁、按什么算；正式的租赁合同和谁签；押金和租金实际交给谁保管。三件事的答案可以各不相同，签约前不逐项问清，退租或维修出问题时就会发现，自己以为的负责方和合同上的负责方不是同一个人。

## 费用先拆名目：中介费按什么基数、由谁付、什么情形退，三问缺一不可

不要只问中介费一共多少，要拆成三个问题逐项问，并把答案记在同一张清单上。

第一问，按什么基数计算。是按一个月租金计算、按租期总租金计算，还是固定金额；如果租期缩短或提前退租，基数是否跟着变。基数不同，总额会差很多，只记一个总数，下次换房或续租时无法复用这条信息。

第二问，由谁付。由租客付、由房东付，还是双方各付一部分，要在付款前确认，不要等到签约当天才在现场得知自己还要多付一笔。如果还有名称不同的服务费、合同费或管理费，逐项问清每一笔对应什么服务、付给哪个主体，避免同一项服务换个名目重复收费。

第三问，退费条件。如果房源信息与实际不符、房东临时取消、签约未成或入住后短期内因房东原因无法继续住，中介费和已付的服务费退不退、退多少、多久退，要在付款前问清并留文字。没有事先约定，事后谈退费通常只能按对方的内部口径处理。

示例假设：假设中介报价时只说有一笔服务费，租客追问后才确认这笔费用按首月租金为基数、由租客承担、签约未成时退还而入住后不退。这个例子只演示三问如何改变一笔费用的含义，不代表任何地方的实际基数或退费规则。

## 合同主体先于价格确认：和房东签还是和中介签，决定出问题找谁

费用问清后，先确认合同主体再谈细节。合同主体通常有两种情形：租客直接与房东签，中介只做介绍和协助；或者租客与中介或其关联主体签，房东不出现在合同里。两种情形下，维修、退租和押金退还的责任方不同，不能只看收款人是谁来推断。

逐项核对三件事。签约方的名称是否与收款方、开票或收据方一致，不一致时要求说明关系并留记录。合同上的联系人和实际处理维修、退租的人是否为同一主体，不是同一人时把实际负责人的联系方式和职责写清。如果是与中介签，继续问清中介与房东之间的授权关系如何证明、租期结束后与谁结算，不要只凭口头保证。

押金交给谁是其中最要紧的一项：交给房东、交给中介代收，还是交给第三方保管，合同里要写明经手人、金额和退还路径。退房时押金扣款要凭证、入住时要留状态记录这些预防办法，见《退房时押金被扣：哪些扣款要凭证，哪些在入住时就能预防》；本篇只强调，押金的经手人和合同主体如果不是同一个人，退还责任更要在签约时写清由谁退、何时退、扣款由谁认定。

## 中介口头承诺的维修与服务，只有写进合同附件才算数

带看和签约阶段，中介常会承诺一些服务：入住前修好某个设备、坏了有人上门、退房时代为协调验收。这些承诺如果只停在口头，换了对接人或过了几个月，通常无从对照。

处理方法与让步项落文字的原则一致：把承诺逐条列成合同附件或补充确认，每条写清事项、负责方、完成时间和未做到时的处理。维修类承诺要写清报修渠道和响应方式，服务类承诺要写清包含的次数或范围，超出范围如何收费。附件由签约双方确认，并与合同正文放在同一文件夹归档。

如果中介不愿意把某项承诺写进附件，就把这项承诺从决策依据里去掉：不要因为一句保证而接受更高的价格或更差的房源条件。能写下来的才计入比较，不能写下来的只当作销售话术。

## 付款凭证按通道留：跨境平台与本地中介的记录差别在可追溯性

最后一项是凭证。跨境平台付款通常自带订单、付款记录和沟通记录，争议时可以按订单编号调取；本地中介收款可能是银行转账、现金或其他通道，记录是否完整取决于付款时有没有主动留痕。各通道具体留什么，《给房东付款留什么凭证：现金、银行转账和平台付款的差别》已经按付款对象拆过，本篇补中介场景的差别。

经中介付款时多留三样：中介费和服务费的收据或确认单，上面写明费用名目、金额、付款人和收款主体；押金和首月租金如果是经中介转交，留转交确认，写清中介只是经手还是保管方；所有沟通记录按日期保存，尤其是费用、退费和维修承诺的确认部分，与合同和附件放在一起。

找房成本要计入第一个月的总账再比较房源。《住 28 晚和住满一个月不是一笔账：平台服务费和税费加在哪里》讲过全包价口径：比较时用包含各项附加费用的总价，而不是只看标价。经中介找房同样适用，把中介费、服务费、押金占用和首月租金并成第一个月总支出，再与直租和平台订房的总价对比，才知道中介的便利到底花了多少钱。

## 签约前清单：费用、主体、承诺、凭证逐项问清

- [ ] 费用基数：中介费和每笔服务费按什么基数计算，是否随租期变化
- [ ] 付款方：每笔费用由租客、房东还是双方承担，收款主体是谁
- [ ] 退费条件：签约未成、房东取消、房东原因无法入住时退不退、退多少、多久退
- [ ] 合同主体：与房东签还是与中介签，签约方、收款方和负责方是否一致
- [ ] 押金路径：押金交给谁、由谁退、何时退、扣款由谁认定，是否写进合同
- [ ] 承诺附件：维修与服务承诺是否逐条进附件，负责方和完成时间是否写清
- [ ] 付款凭证：费用收据、押金转交确认和沟通记录是否按日期归档
- [ ] 第一个月总账：中介费、服务费、押金和首月租金是否已并入总支出再比较
