# 合租分账：水电、工位与公共消耗怎么拆

这篇适合谁：和另一个人或几个人合租一整间房、打算住一个月以上的人，尤其是房间条件不一样、水电要自己缴、还要共用客厅或工位的情况。如果你是各租各的房间、账单由房东分别收，这篇的大部分内容用不上。

先分清三件事。事实部分：合租纠纷多数不是金额算错，而是入住前没有说清拆法，事后各按各的理解算。预算假设部分：这篇不给任何具体价格和单价，金额全部用比例和公式表达，你代入自己那间房的实际账单即可。建议部分：给一套默认拆法和谈例外的方法，默认拆法不是唯一正确答案，是谈不拢时的起点。

站内已有的两人预算类文章算的是总量：一间房一个月总共要准备多少钱。这篇算的是内部分账：总量定下来之后，几个人之间怎么拆才算说清了。两篇配合看，先定总量，再定拆法。

## 房租按房间拆，主卧和次卧的差价用三个因子谈成一个比例

房租不要默认对半。房间条件不同，对半分就是把争议推迟到住进去之后。差价怎么定，看三个因子就够了。

一是面积，用房间的实际使用面积比，不要用整间房的建筑面积比。二是独卫，有独立卫生间的房间，日常便利程度不同，这一因子通常对差价的影响排在面积前面。三是采光和朝向，长时间在房间里工作的人，对这一项的感受差异最大，所以它最需要当面谈，而不是套系数。

谈法是把三个因子谈成一个比例，而不是逐项算钱。具体做法：先按面积算出一个基础比例，再问一句，有独卫、采光好的那间，愿意在这个比例上再多承担多少，用一个双方都接受的整数比例定下来，比如总租金记为 R，两间房分别承担 R 乘以各自的比例系数，两个系数之和等于一。示例假设：若谈定的系数是零点六和零点四，差价就是 R 的零点二倍，这只是演示比例的算法，不代表任何一间房的实际差价应该是多少。

比例一旦定下，写下来，存在两个人都看得到的地方。后面水电和公共消耗的拆法可以和这个比例不同，不要默认所有账都按房租比例拆，每类账单独定。

如果客厅或阳台被其中一人长期当作固定工位使用，这部分要单独算，不能混在房租比例里。算法是：先约定工位占用的计价方式，可以按月折算成一个固定比例加到使用人的房租系数上，也可以按实际使用的天数折算。哪种简单选哪种，关键是入住前定，不要住了一个月再回头补算。

## 水电按表拆，读表拍照的方法和退房证据链共用一套

水电的默认拆法是按表、按用量，不按房租比例。没有分户表、只有总表的情况，用人头平均是可接受的起点，但有两个例外要先说清：有人长期在房间里用大功率设备，或有人经常不在家，用量明显偏低，平均分就不合适，要改成按估算用量比例拆，估算的依据也要写下来。

操作上只有三个动作。入住当天，两个人一起读一次水、电、燃气表的读数，各自拍照，照片带日期。缴费周期每次缴费时，先拍表，再按公式算：本期费用等于账单总额，个人应付等于账单总额乘以个人用量占比；没有分表时，个人用量占比就用约定的人头比例或估算比例代替。退房当天，再一起读一次表拍照。

这套读表拍照的做法，和《退房时押金被扣：哪些扣款要凭证，哪些在入住时就能预防》里的入住证据链是同一套：入住读数是起点，退房读数是终点，中间每次缴费的照片是过程记录。押金结算时房东如果提出水电未结清，你拿得出完整的读数链，就不需要再临时找凭证。发布前需按合同原文与官方来源复核水电结算条款，各地和各房东的结算方式以所签合同为准。

## 公共消耗按人头拆，耗材和清洁要么轮值要么折现，二选一

公共消耗分两类，拆法不同。第一类是耗材：垃圾袋、清洁剂、卫生纸、滤芯这类用完要补的东西。金额通常不大，默认按人头平均，设一个简单的记账方式，谁买了就记一笔，月底按人头结清，不要每买一次结一次，次数多了记账本身就成了负担。

第二类是清洁：公共区域的打扫没有金额，但有时间成本，最容易产生不满。处理方法只有两种，入住前二选一。一种是轮值，把频率和范围写清，比如每周一次，范围只包括厨房、卫生间和客厅地面，不包括各自房间。另一种是折现：一人固定承担清洁，另一人按约定的比例多付一部分公共费用，或承担全部耗材采购。折现的比例用公式谈即可：清洁折现金额等于双方约定的月度折算值，不需要去查任何家政行情价，你们两个人认可这个时间值多少钱，它就是多少。

例外情况先说清：如果有人频繁带人回来使用公共区域，或有人长期出差不在，公共消耗的人头比例要不要调整，在入住时就约定触发条件，比如连续不在超过多少天，当月公共消耗免除或减半。没有触发条件的约定，事后很难执行。

## 有人提前走，分账按交接日切断，后面的账由留下的人重新谈

合租中途有人提前走，分账纠纷通常出在切断日没定。原则是三条。第一，所有按用量和按人头的账，以实际交接日为界，交接日之前按原约定拆，之后与离开的人无关。第二，交接日当天重复入住时的动作：一起读表、拍照、结清截至当天的公共消耗记账余额。第三，房租部分最复杂：如果离开的人的房间空置，空置期间的租金由谁承担，取决于你们和房东的合同是整租还是分租，这一点以所签合同原文为准，不能套用默认规则。

提前走本身涉及的违约金、转租找人接手、机票改签等止损算法，不在这篇展开，见姊妹篇《提前退租止损：违约金、转租与改签一起算》。这篇只提醒一个衔接点：如果离开的人找到了接手人，新的人从接手日起，房租比例、水电拆法、公共消耗轮值要重新确认一遍并写下来，不要默认沿用上一任的口头约定。

收尾清单，合租入住第一周内做完：

1. 房租比例已经按面积、独卫、采光谈定并写下来，工位占用单独计价。
2. 入住当天的电表、水表、燃气表读数照片，两人都存了一份。
3. 水电拆法已定：按表、按人头还是按估算比例，例外情形写清。
4. 公共耗材的记账方式已定，清洁选了轮值或折现中的一种。
5. 提前离开的切断规则已约定，触发条件写明。
6. 以上五项都存在两个人都看得到的一份文档里，不只在聊天记录里。
