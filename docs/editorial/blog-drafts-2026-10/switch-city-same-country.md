# 一座城住腻了先别换国：同国家换城的低成本试法

这篇适合已经在一座城住满一两个月、想换地方，但不想重新办一遍停留、支付和生活手续的人。也适合第一次出国长住、第一城选得不算错、只是某个具体条件不合适的人。不适合停留期限快到、必须离境才能解决身份问题的人，那种情况换城解决不了，要先处理停留本身。

先把三件事分开。事实是：换国通常要重新确认入境条件、停留天数、支付方式和常用服务能不能沿用；同国换城一般只换房和街区。预算假设在下文单独列，按单人、整间房、三十晚算，未知项留空不填零。建议是：先判断问题出在哪一类，再决定换城、换街区还是换国，不要用一次搬家同时解决所有问题。

## 换城能解决气候、房源和社交问题，解决不了停留上限

换城能处理的问题有明确边界。同一国家内，两座城的气候可以差很多，房源结构也可以差很多，一座城整间房难找，另一座城可能以另一种户型为主。社交也是同理，第一城没有你能参加的活动或常去的场所，第二城可能有，这类问题换个地方就有机会变。

换城处理不了两类问题。一是停留上限，停留天数通常按国家算，不按城市算，在一国境内从一座城搬到另一座城，不会多出新的天数。二是工作结构，如果问题是会议时段、任务量或协作方式，搬到哪座城都还是同一套工作安排，这类问题要和团队谈排法，不是换地址能解决的。把这两类先排除，剩下的才值得用换城来试。

## 第二城只和第一城拉开一个变量，才知道换得值不值

选第二城时，建议只拉开一个变量。如果第一城的问题是气候，第二城就选气候条件明显不同的，其他条件尽量接近，包括房型、预算档和工作时段。如果问题是房源，第二城就优先看房源结构，气候和氛围先放到后面。同时改三四个变量，住完也说不清到底是哪一项起了作用，下一次选城还是只能凭感觉。

具体排法是列一张对照表，左边写第一城的实际问题，用一句话写清，比如整间房选择少、某个月份太热、晚上没有可去的地方；右边只写第二城对应这一项的情况，其他项标注与第一城相近或待核对。这样列完，第二城的候选通常会收窄到少数几座，不需要在几十座城里重新选一遍。

Roamorrow 帮中文远程工作者选城市，站内有三百五十城目录，可以把同一国家的城市放在同一张表里连排着看。六维评分的默认权重是安全百分之三十、花费百分之二十五、气候百分之十五、氛围百分之十五、网络百分之十、生活百分之五。这里要分清，网络与安全是评分，不是实测结果，评分适合做第一轮筛选，订房之前仍要向房东或平台核对具体的网络和门锁、楼道等情况。

## 换城不重置停留天数，先把停留总账算完再订房

订第二城的房之前，先算一笔停留总账。算式很简单：本国允许的停留总天数，减去已经住过的天数，再减去计划在第二城住的天数，结果必须大于零，还要留出离境和改签的余量。天数从入境那天怎么起算、能不能延期、不同入境方式口径是否一样，各国规定不同，本文不下结论，发布前需按当期官方来源复核，读者执行时也要按自己入境时的官方说明再核对一遍。

大陆护照入境标签可以做第一步参考，Roamorrow 站内按免签、电子签、需签证给城市所在国家标注。标签只说明入境方式这一层，不等于允许停留的天数，也不等于延期条件，两个数字要分开查。顺序建议是先看标签确认入境方式，再查停留天数，最后才看房源，不要反过来先订房再算天数，退订的成本通常比查一次规定高。

预算也要按同一口径重算，不能拿第一城的账单直接套。规划单位统一为单人、整间房、三十晚，表格可以这样列：

| 项目 | 第一城三十晚实际 | 第二城三十晚预估 | 核对方法 |
| --- | --- | --- | --- |
| 房租 | 按合同或订单填 |  | 按整间房、三十晚向平台或房东询价 |
| 水电与网络 | 按账单填 |  | 问清是否包含在房租内 |
| 城际交通 | 无此项留空 |  | 按实际路线查当期班次与票价 |
| 押金与退订条件 | 按合同填 |  | 订前书面确认金额与退还条件 |

表里填不出的项留空，留空代表还没核对，不代表这项花费是零。两城对比时只比已经核对过的行，未核对的行补完再下结论。

## 先试住两周，再决定要不要搬全部行李

决定换城之后，不建议直接把全部行李搬过去并签下长租。先在第二城试住两周，房型和正式住的时候保持一致，用整间房，不要用酒店或合住的条件来推断整月住下来的情况。两周里按正常工作日过日子，该开的会照开，该买的菜照买，该走的路线照走，这样测出来的才是工作日的日常，不是假期的印象。

试住期间只核对三件事，就是当初拉开的那个变量有没有变、停留总账和预算表能不能对上、原来的支付和常用服务能不能照常使用。三件都对上，再签三十晚的房并搬行李；有一件对不上，先回第一城或换备选城市，不要在没核对完的情况下把长租签掉。行李的另一半可以先留在第一城或找地方寄存，具体做法见本系列第 38 篇行李寄存的做法，试住失败时退回去也少一次搬运。

同国城市在同一张表里连排，还有一个实际好处是决策成本低一档：入境标签相同，停留算同一笔账，需要重新核对的只有房、街区和那一个被拉开的变量。换国则要把入境、停留、支付和生活服务整套重查，适合问题出在国家层面时再做，不要为一个城市层面的问题付国家层面的成本。

## 换城之前按这张清单逐项打勾

第一，写清要解决的问题属于气候、房源、社交中的哪一类，并确认不属于停留上限和工作结构。第二，第二城只与第一城拉开一个变量，其余条件尽量接近。第三，停留总账算完且留有余量，入境与延期口径发布前需按当期官方来源复核，自己执行前再核对一次。第四，预算表按单人、整间房、三十晚填完，未知项留空并补核对。第五，先试住两周，三项核对都通过，再签长租、搬全部行李。五项里有任何一项没完成，先补那一项，不提前订不可退的房。
