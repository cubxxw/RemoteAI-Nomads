# Roamorrow：50篇文章的发布顺序

编排日期：2026-10-22。第1–4篇为本轮四个专题；其余为选题，不表示已经核验、撰写或发布。顺序按读者决策路径和现有资料安排，不是搜索量排名。

本轮状态：第1–4篇为新建专题稿（`/guides/november-nomad-destinations/`、`/guides/monthly-budget-5000/`、`/guides/beijing-time-remote-work/`、`/guides/chinese-passport-long-stay/`），与现有城市月住指南并行，不属于旧稿改写；第5–50篇仍是选题，尚未启动。后续选题与现有城市指南或本轮四篇意图重合时（如11–20、31–33、38–39、41–45），在原文扩写或补章节，不新建重复URL。

每个选题发布前复核价格、政策、来源与季节。已有文章覆盖同一搜索意图时，优先扩写原文或补章节；不为凑50个URL拆出重复文章。不要把标题中的预算条件写成保证可订价格。

写作采用解释型生活服务稿：先说适合谁，用一个工作日或一张账单展开；事实、预算假设和体验分别说明。借鉴公开报道的清楚结构，不复制作者措辞，也不编造第一人称经历。
