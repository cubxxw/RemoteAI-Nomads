# Roamorrow Nomads SEO 分析与优化

这份记录保留原工作区的初始审计。整合当前主分支后的版本与检查结果见[发布前记录](2026-10-29-release-preflight.md)。下文的“当前工作区”均指初始审计时的原工作区。

2026-10-29。范围为 `https://roamorrow.com/nomads`，包括公开 HTTP 抽查、当前工作区的完整发布快照和路由测试。

网站已有可直接读取的正文、规范网址和站点地图，基础抓取条件正常。本次完成了内部文件入口保护、静态跳转修复和页面结构化数据补充。改动已在本地验证，尚未部署。没有读取 Search Console，实际收录量和搜索曝光未核验，点击率与排名变化也无法判断。

线上站点地图有 452 个唯一地址。当前工作区重建的快照包含 683 个 HTML 页面，其中 423 个规范页面进入站点地图。两组数据来自不同版本，不能混算覆盖率。当前工作区保留了其他未提交修改，且落后于远端主分支。本次没有从这里发布生产版本。

## 已核实的情况

| 项目 | 观察与处理 |
| --- | --- |
| 抓取入口 | 根目录 robots.txt 公布了 Nomads 站点地图，线上地图返回 200。列出地址不代表已经收录。 |
| 旧域名迁移 | 旧清迈城市页返回 308，目标为新站对应城市页。 |

| 无效页面 | 抽查不存在的页面返回 404，并带 noindex，没有假装成正常内容页。 |
| 薄内容边界 | 抽查泰国国家页为 noindex，当前快照的国家页未进入地图。 |
| 内部文章文件 | 线上原始 HTML 返回 307，跳转路径缺少 `/nomads`。本地已禁止直接访问内部文章和快照目录，返回 404/noindex。公开指南及故障回退仍从内部文件读取内容。 |
| 静态跳转 | 同源静态资源的跳转现在保留站点前缀、查询参数和锚点，外部目标保持原样。 |
| 结构化数据 | 保留 Place、Article 和已有对比页图谱，补齐城市页的页面与面包屑信息，并补充指南等页面的结构化数据。预览和禁止索引页面不增加这组信息。 |

原始 HTTP 抽查及后续重试保存在 [线上证据](2026-10-29-live-sample.json)。部分请求发生 TLS 中断，成功重试和失败记录均保留。单次请求耗时不用于评价用户实际加载速度。

## 完整快照检查

新增 `npm run seo:check`，检查站点地图目标是否存在、是否禁止索引，以及 canonical 是否一致。它也检查页面标题和摘要，同时检查主标题与结构化数据，并核对规范页面是否能通过正文链接发现。相同 canonical 的兼容入口不会被误算为独立重复页面。

重建后的 423 个规范页面通过检查，无地图目标错误、重复标题摘要或孤立页面提示。原快照中 350 项城市面包屑缺失和 6 项结构化数据缺失已消除。现在只剩首页与排行别名的 HTML 体积提示。结果见 [快照审计](2026-10-29-snapshot-audit.json)。

这项检查验证本站生成物的结构与一致性，不等同于 Google 的富媒体结果验证，也不能证明 Google 已采用所声明的规范网址。面包屑的实际展示仍由搜索引擎决定，依据见 [Google 面包屑文档](https://developers.google.com/search/docs/appearance/structured-data/breadcrumb)。

## 后续优先级

首先补上 Search Console 的效果证据。按页面和查询词查看最近 28 天的曝光与点击，再对已有曝光但点击较少的页面调整标题和开头。没有这些数据时，先不凭页面数量判断内容成效。

其次测量首页真实加载。线上首页 HTML 为 671,525 个未压缩字节。当前本地版本约 762 KB。旧本地快照中，排行数据占约 472 KB，说明嵌入数据值得继续检查。下一轮应同时记录实际传输量与移动端 LCP、INP、CLS，再决定是否压缩数据表达或分批读取。保留服务端正文和完整城市目录，避免加载优化削弱内容发现。

内容优化围绕已有页面分工展开。城市页回答目的地是否合适，月预算指南解释单人 30 晚的具体住法，对比页回答两城如何取舍。预算和月份专题负责连接这些页面。优先用搜索查询检验这种分工，再补充缺失信息，避免围绕同一问题反复发布近似文章。

临近 11 月，应核对季节入口是否仍准确表达其适用月份。日期、报价口径和官方来源按实际复核结果更新，不用当天日期替换历史资料日期。站点地图中的 lastmod 也应继续对应真实内容更新。规范网址与内链原则参考 [Google 规范网址文档](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls)。

## 验证与发布边界

针对性测试覆盖了编码后的内部路径、根域部署、旧域名、HEAD、静态跳转及公开指南和故障回退。独立审查发现的异常结构化数据输入也已补测试修复。216 个文件通过语法检查，全量 453 项测试通过，Worker 打包检查通过。
