# 旅居专题入口

用户指出分类挤在同一排、区别不明显，读者不知道怎样使用。本轮只调整指南索引的专题入口，沿用原有照片、品牌与文章内容。

采用六个短入口：全部专题、选目的地、租房与开销、季节与换城、签证与工作、对比与工具。每个入口同时显示一句范围说明和实际篇数；桌面三列两排，手机两列三排。选中项使用现有深棕色，边框和文字同时变化。相较单排短标签，这种排列能保留分类解释；相较新增侧栏，不挤占文章和图片空间。这是本轮实施判断。

初始展示全部专题。选择分类后仅显示该组，当前数量明确可见；“全部专题”恢复全文列表。保留原分组锚点，使用正常链接及URL片段，支持键盘、浏览器前进后退和直接打开分类。没有脚本时仍能跳转各组，所有文章保留服务端链接。现有14篇未分类专题补充独立分类字段，原系列编号、正文与修改日期保持不变。未知分类保留在“更多专题”，不静默丢失。

验收覆盖全部64篇各出现一次、计数真实、切换与回退、未知片段、无脚本、320/390/768/1440宽度以及键盘焦点。发布同步公开回退页，核对正式域名实际画面。
