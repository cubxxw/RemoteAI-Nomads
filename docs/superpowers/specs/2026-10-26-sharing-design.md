# Roamorrow 分享：图片、内容与接收体验

日期：2026-10-26。状态：用户已选择「旅行编辑手记」并明确要求直接实现；详细取舍由实施者负责。

## 要解决的问题

分享者应该能把选城过程里值得留下的内容发出去；接收者无需先了解 Roamorrow，就能看懂地点、取舍和数据限制。图片是主要作品，链接负责还原上下文、核对来源和继续操作。延续项目已有的字体、森林绿、真实城市摄影和数据边界。

用户要求每个维度满分 100、超过 96。本方案将发布门槛设为各维度至少 97，逐项通过；未测维度记为未测。检查通过率、维护者的视觉判断和真实用户评价分别记录。

## 当前证据

本次检查基于工作区 `2a55dd80`，保留已有未跟踪的 public MCP 设计文件。

- `public/modules/rank-ui.js` 有排行链接弹窗：先显示，再异步复制；保留手动复制、会话隔离和关闭后的焦点恢复。
- `content/city-guides/guide-tools.mjs` 已有预算链接、摘要、清单导出等独立动作。预算情景包含 tier、nights、season、work、currency、housing；housing 是用户手填房租，不能被全站分享入口默默带出。

- `npm run check`：401/401 通过，2026-10-26；当前终端 Node 22.22.0，项目声明 Node ≥24。正式候选验收须在项目支持版本执行。
- 本地浏览器打开排行并激活分享，确认现有弹窗立即显示链接且可关闭。基线图：`web/docs/images/share-2026-10-26/baseline-dialog.png`。未据此评分其他页面或设备。

## 方向取舍

推荐「旅行编辑手记」：以实际对象为主角，真实照片建立地点感，标题和最多三组关键信息帮助判断。正文像同事分享一份认真挑过的资料，避免口号、夸张胜负与装饰性标签。主视角是摄影编辑，网格与字阶负责清晰阅读。

另一可行方向是「城市数据报告」：表格和多指标主导，适合反复比较；代价是缩略图阅读更费力，图片更像工具截图。前者更贴合用户强调的阅读意愿和品味，但这仍是维护者推荐，尚非用户批准。

两者都应复用一个内容模型和导出机制。对比卡可保留结构化双列，不能为了视觉一致强行给所有对象套一张大照片。2026-10-26 用户选择第一条路线并授权直接实现。

## 分享对象与入口

“覆盖所有可分享的地方”以产品对象和状态为边界，并保留通用文件、文字、链接出口；不声称覆盖每个社交应用的原生发布接口。

| 对象 | 入口 | 接收者看到的内容 | 需要保留的状态 |
| --- | --- | --- | --- |
| 排行与筛选视角 | 现有分享按钮 | 选城条件、前三城及预算口径；明确只是该视角的部分结果 | 搜索、地区、预算币种、月份、权重、其他公开筛选；无显式月份时固定本次实际月份 |

最后两类可能包含个人兴趣或个人内容，必须以可核对预览为授权边界。全站普通分享不能默认分享整个对话、个人方案或本机清单。

独立建设者审阅提出个人双城方案的范围问题。本轮由实施者确定：默认公共比较；允许显式选择后导出个人比较图片/文字，标记“个人填写”，不将其逐项金额、来源文字或预算上限写进公开链接，不新增会话/个人方案的服务端存储。接收者打开链接仅恢复公共比较，面板明确说明。

## 分享面板与操作

桌面使用居中对话框，手机使用可滚动底部面板。统一结构为：标题和关闭 → 真实导出预览 → 平台/比例选择 → 保存图片主按钮、系统分享 → 复制文字/复制链接 → 可展开的来源与分享范围。默认保留一个推荐比例，其他比例折叠在选择器里。

进入面板时立即显示可复制链接与公开文字，图片独立准备，不等待剪贴板、字体或照片才打开面板。不得打开时自动写剪贴板；复制由明确按钮触发。原链接弹窗的早期准备状态、关闭恢复焦点和会话隔离需要保留相同保证。

图片准备完成后启用保存、复制图片和系统文件分享；系统分享调用发生在用户的那次点击内，避免异步生成耗尽原生分享所需的用户激活。取消系统分享是正常退出，不提示为错误，也不自动再次弹出或下载。

不支持系统分享或图片剪贴板时，保存文件和手动复制仍可用。照片加载失败时显式显示“照片暂未载入”，允许重试或选择文字版；不能导出后才悄悄发现图片少了。导出失败保留预览和链接并可重试。关闭面板取消过期结果回写；释放对象 URL，避免长时间使用后积累内存。

微信、小红书、Instagram 采用“保存图片 + 复制配文”的真实可用路径。平台选择只改变比例和提示，不能假装已经发出。X、Telegram、WhatsApp、LinkedIn 可在确认各自官方机制后增加打开编辑器的链接，最终发布始终由用户完成；这些不是图片出口成立的前置条件。

## 图片作品

每张图首先回答“这是什么、对我有什么用、数字应该怎样理解”。顶部品牌只保留轻量 Roamorrow 标识和内容类别，主标题最大，照片与事实分区。一个重点数字组不超过三个。关键限制和单位紧贴数字，不藏到扫码后才可见。

保留现有 Inter 与中文系统字体，深色正文配清淡纸面和少量品牌绿。字号、行距、数字对齐从最终 360px 阅读宽度反推。不要用微小英文、重复胶囊标签、巨型二维码或未经核对的营销句子填空间。标题允许自然换行；超过容量则改用更长模板或分页，不能缩字直到看不清。

真实照片使用原始本地资产受控裁切，保留主体、照片作者和许可。分享作品新增图像不使用虚构地点照片替代真实城市。现有生成场景及其标签保持原样；分享模板没有合适真实照片就用文字排版。

2026-10-26 用户明确要求图面删除来源提示、署名/许可证行与脱离指标的日期。照片作者、许可和完整来源保留在配文、展开详情与原页；图中只保留与事实相邻的日期和可恢复的二维码/地址。长署名不再挤占版面或触发文字版。二维码若纳入实现，必须来自本地可审计编码器，编码完整的同一分享链接，并在最终缩略图和真实手机扫描验证；无空间时保留清晰短显示域名和同一配文中的完整链接，不能绘制装饰性伪码。

下列为本产品的导出预设，不宣称是所有平台的强制规格：

| 预设 | 像素 | 主要使用情境 | 版式变化 |
| --- | --- | --- | --- |
| 编辑竖图 | 1080×1440，3:4 | 小红书、微信聊天、收藏阅读 | 照片、标题、事实依次阅读 |
| 通用方图 | 1080×1080，1:1 | 朋友圈、群聊、常见信息流 | 控制摘要长度，重点仍完整 |
| 信息流竖图 | 1080×1350，4:5 | Instagram、LinkedIn 等图片帖子 | 原生重排，不裁掉竖图底部 |
| 横向卡片 | 1200×630 | 公开链接预览和横图场景 | 照片和文字并置，缩短次要信息 |
| 全屏竖图 | 1080×1920，9:16 | Story / 状态类内容 | 信息居中、上下留可配置空区；在对应应用验收遮挡 |

默认 PNG 保证中文文字清晰；支持压缩后的 JPEG 作为照片导出的文件大小回退，透明图不强转 JPEG。产品目标为导出 ≤4 MiB；不满足则压缩并复看，不删除事实/限制以减小文件。所有预设从同一快照独立布局，不用一张长图机械裁切。

## 内容模型与一致性

共享纯数据模型由对象的公开数据构建：kind、标题、摘要、canonical、可恢复 URL、实际月份、facts、caveats、sourceRecords、photoRecords。数据保留原始数值、单位、适用对象、采样/核对日期和来源；字体与版式不能修改语义。

同一次打开分享面板固定一份快照。预览、图片、配文、链接均从此生成；切换平台只变排版。页面数据之后变化时提示重新生成，或重新打开时获取新快照，不能让导出的数字与当前展示不一致。

URL 使用对象级白名单和既有规范化函数，删除跟踪参数、令牌、未知参数和非公开个人字段。排行继续复用 stateParams，并固定实际月份以防跨月复开改变含义。guide 的 housing 不能混入普通公开白名单；选择包含个人填写时，面板须显示确切数值和接收范围。重新打开链接只恢复已承诺的公开参数，不能依赖发送者的 localStorage 才正确。

展示日期区分资料采样、资料核对与图片生成；不把 2026-10-26 的生成日期贴为现价日期。缺失用“待补充/待核验”并保留原因，不能补 0。历史网络分标 /10，不写 Mbps；历史气候不写成天气预报；旧入境标签不写成合法远程工作的保证。已发布的暂勿前往提醒及其限制不能在分享时被摘要删掉。

助手答复是独立的内容类型，不能通过读取页面 innerText 把侧栏历史、隐藏草稿和工具日志混入图。来源缺失的回答不能被包装成“已核实指南”；只允许以其实际状态分享。

## 接入现有项目

沿用 Workers + 原生浏览器模块，不引入大型页面截图依赖。以纯内容模型、确定性 Canvas 排版器、分享交互三个边界拆分。中文换行按真实字体测量；不对整个 DOM 做截图，避免带出本机个人区域、浮窗或加载中的骨架。

预览若使用 Blob 图片，仅对普通页面、指南和公开备用响应的 img-src 增加 blob:；脚本、网络和样式策略保持原边界。原生 Canvas 和 Blob 下载不需要远程抓图服务。

全站普通页面在 shell 中接入轻量入口，点击才加载渲染器和所需照片；排行由现有处理器提供已提交的 state 和同一 rankCities 结果。城市和比较由实际数据显式注入安全 JSON，保留原方法和时间。指南通过 `augmentGuideRuntime` 的响应时附加资源接入，不改批准源稿、原摘要、核对日期、素材或 publication.json。

公开元信息应提供完整标题、摘要、绝对链接、实际图片尺寸、图片替代说明及 Twitter 大图类型。只有能确定与页面对应、可公开读取的图才写入元信息。动态偏好链接不能谎称其预览一定展示个性化前三名：若首期仅通用预览，明确该预览代表栏目，真实条件在打开链接后恢复。用户手填参数与助手正文绝不能进入公开抓图接口或持久缓存。

现有 published fallback 页面需要随最终候选重建并检查挂载路径；数据库限流时不能回到没有新分享入口的旧页面。离线/限流/资产失败分别验收，不把本地正常请求当作线上保证。

## Eval：八个维度各自达到 97

每维 100 分、五个子项各 20 分；每子项以五个可重复观察点各 4 分评估，可按实际完成比例扣到 1 分。每个观察点先标记可验证方式、环境和证据，未测记 null，不自动给分。维度得分不能用其他维度补偿。所有 8 维已测且最低分 ≥97、无关键失败，才允许写“达到本轮门槛”。

| 维度 | 五个子项 | 主要证据 |
| --- | --- | --- |
| 内容覆盖 | 排行；城市/对比；指南/计算器；清单/目录/来源；显式选择的个人对象/答复 | 逐入口完整任务与可恢复对象清单 |
| 信息准确 | 原始数值；单位口径；月份日期；来源限制；链接与图片一致 | 原数据→快照→作品逐项核对及反例 |
| 隐私与授权 | 白名单 URL；报价选择；答复选择；无隐形区域；无第三方上传 | 标记私人哨兵内容，扫描全部图片文字/链接/请求 |
| 操作便捷 | 入口可发现；主操作步骤；即时打开；取消恢复；失败回退 | 首次操作的步骤、时间、错误和重试原始记录 |
| 阅读理解 | 地点主题；主要比较；金额口径；限制识别；继续查看路径 | 受试者回答正确率与误解原话 |
| 视觉品味 | 编辑层级；摄影裁切；中文排版；留白与秩序；愿意保存/转发 | 盲序 A/B、真实尺寸图册和目标用户评分 |
| 平台适配 | 五种比例；压缩后可读；原生文件能力；图片/文字回退；真实应用接收 | 最终文件、设备/应用版本、实际发送预览/接收图 |
| 稳定与可访问 | 键盘/读屏；窄屏/大字；资源异常；异步竞态；耗时/文件与内存 | 浏览器检查、真实设备、性能数据及日志 |

自动测试只覆盖可机械判断的事实、隐私、URL、排版容量与错误恢复，输出通过/失败和证据，不转换成品味分。维护者可做有据的设计审查，标明“维护者评审”；模拟角色仅用于压力测试并标明模拟，不能算真实用户。

### 零容忍失败

任何一项出现即不通过，停止分数包装：地点配错照片；金额/币种/月份/来源失真；缺失变成 0；未告知地泄露报价或对话；限制被隐藏；图片缺字裁字；关键文字在目标尺度无法阅读；普通分享出口全部失败；二维码编码错误；平台取消触发意外发送；焦点无法退出或返回。

### 固定回归集与保留样本

至少 32 个核心任务，每个保存输入、预期、实际、导出文件、截图、失败/重试。额外长标题、混合中英文、超长署名和缺项样本留作最终验收，不能全部拿来调模板后又称独立验证。

| 显式选择 2 | 收藏的公开城市集合；含私人哨兵的单条答复与引用 |
| 恢复与安全 8 | 剪贴板待决/拒绝；字体失败；照片失败；文件分享取消；导出超时重试；A/B会话交错；未知参数与恶意文字；挂载路径与备用页面 |

每种对象至少导出五种预设。全量自动批次检查尺寸、可解码、文件大小、文本容量/边界、来源字段和私人哨兵；代表长内容逐图人工看原尺寸和 360px 显示宽度。不能仅检查 CSS 没有溢出就宣布压缩后的图片可读。

目标环境为 Chromium、Safari/WebKit、Firefox 的当前可用版本；320/390/768/1440 宽度，200% 页面缩放和系统大字；iPhone Safari、Android Chrome 与目标应用至少各一部真实设备。浏览器能力模拟只能验证分支，不能记作真实系统分享成功。

### 目标用户与盲评

招募至少 8 位有长期旅居/远程工作经验、近期实际分享过城市或预算资料、重视摄影编辑/信息质量的中文用户。招募标准可观察，不用“最有品味”作为无法检验的身份判断。覆盖预算谨慎者、经常开会者、重视当地生活/摄影者和独行者；不以角色设定冒充招募结果。

让用户在不看网站的情况下读取收来的图片：5 秒说出地点与主题；15 秒解释一项金额、对应月份和一条限制；30 秒找到可继续核对的入口。另从当前页面独立完成保存/发送操作，记录首次结果、步骤与重试。时间是本产品研究目标，不宣称已有结果。

盲评将本轮候选、旧作品和一份同内容对照随机排序，不展示版本名称和预期分数。评分前先做理解题，再评分阅读与视觉，避免只问“好不好看”。保存原话、各项评分分布和有效人数。每维参与者均分≥97、任何关键误解为零、无人低于90是候选研究门槛；未满足就迭代，不能剔除低分用户提高平均分。样本仍不能证明所有数字游民都喜欢该设计。

### 性能与持续运行

记录测试设备和网络。面板出现目标 ≤100ms；本地字体/照片热缓存下导出 p95≤2s，受控冷缓存目标≤5s；4 MiB 内保留完整信息。测不到时记未测。超时显示重试，不阻断链接和配文。

拟设 `npm run evals:share` 执行固定回归和作品图册，输出机器结果及待人工评审项；`evals:share:release` 只在每维有对应证据、最低97且无失败时通过。JSON 结果区分 automated、maintainer、target-user 和 platform-receipt 四类证据，记录源提交、环境、模板版本、样本版本、日期与文件路径。真实用户/平台记录不由脚本自动生成。两条命令尚未实现。

## 验收与交付界限

交付应包含可用代码、真实导出图片图册、操作与异常记录、可重复 Eval、逐维结果和剩余未测项。普通检查、Worker 构建、指南原稿/资源指纹、公开备用页面及挂载路径校验都须通过。评审最后再对照基线检查全站分享覆盖。

实现与本地验收不自动代表已部署、已真实发送到所有平台或已通过目标用户研究。正式发布按仓库现有发布流程执行。不能为了满足 97 门槛虚构设备、受试者、平台回执或主观分数。
