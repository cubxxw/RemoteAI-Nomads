# 阅读体验与维护体系迭代计划

> 2026-10-23 整合说明：本计划中的“首页／README”指原指南快照；现行指南入口为[目的地笔记](../../../guides/destination-notes.md)，项目 README 保留网站与生成的季节推荐。分工、历史评分与验收结果不因迁移改写。

用户已要求开 5 个 sub-agent 深度迭代，重点优化阅读体验、制定固定评分标准并设计测试 Action。沿用当前工作区已有成果，不覆盖上一轮修改。

## 范围与分工

- 1：首页阅读路径与城市卡（README）。
- 2：方法、比较模板与落地清单（guides）。
- 3：来源维护、数据防护与贡献流程（data 说明、数据检查器、贡献指南）。
- 4：阅读结构回归与 GitHub Actions（独立脚本/测试/工作流）。
- 5：按固定评分标准独立评估和复审（research 迭代报告）。

## 固定约束

- 评分依据 [阅读质量标准](../../../research/reading-quality-rubric.md)，不替换为自动检查比例，不虚构真人测试。
- 保留原始价格、事实日期、来源状态与稳定锚点；不扩大成网站工程，不添加没有来源的旅游事实。
- 脚本运行使用 Python 3.10+ 标准库；浏览器预览是临时的本地 Markdown 渲染，不宣称等同 GitHub 或用户研究。
- 各 agent 仅编辑分配文件。先完成第一轮，再按独立复评修第二轮，最后做实际浏览器与自动化验收。
- CI 无密钥、无外部消息、无发布/自动改推荐；本地与云端执行分别说明。
