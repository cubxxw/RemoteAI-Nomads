# 分享带走路径（GET-268 → GET-271）

依据四条 Linear 需求及 GET-257 已合并的品牌规范，在独立分支上依次实现，不改排行榜、文章和私人数据的默认分享范围。

1. GET-268：`web/public/modules/share-ui.js` 与 `web/public/share.css`。保存为唯一实心按钮；复制链接和系统分享用文字按钮；配文常显；完整 URL 只在配文和复制结果中保留，权限失败时提供可选择的备用字段。保留分页、重试与整组下载。
2. GET-269：`share-model.js`、`share-render.js` 与城市页的分享快照。城市卡固定四项：历史月花费、所选月历史均温、大陆护照入境标签、旧网络评分；数据日期和旧资料标记紧随指标。眉题带月份，已有标签最多三枚。不编造新标签。普通说明和署名放配文，官方出行提醒继续进入图片。两种格式共用同一信息结构。补充缺失值、四格布局、提醒与配文保留的行为测试。
3. GET-270：分享面板只显示原生单选分段「竖图／文字版」，均为1080×1440，切换即重新生成；底层五种比例能力保留供现有导出评估使用。切换时保留配文编辑，忽略已取消的旧渲染。
4. GET-271：纸色 #FAF8F6、墨色 #1F1A14、主按钮深棕 #5D3000、辅助色沿用品牌金。检查桌面、390px、320px、键盘、焦点、错误恢复和减少动态效果。

验证：先运行现有分享测试作为基线（21/21通过）；浏览器检查真实导出与交互，模型/排版测试覆盖零分和缺失区别、2×2对齐、分页、长链接二维码、出行提醒不丢；最后运行项目完整检查与构建。记录实际失败，不能把维护者截图判断写成用户研究或目标应用接收验收。
