# 数据与方法

README回答“这个月去哪”，网页提供筛选与对比，具体来源集中在这里。[打开网站方法页](https://nomads.cubxxw.com/about/) · [十月逐城资料](../../guides/seasonal-2026-10.md)。

## 主表怎样选城市

主表取网站本期综合视角的前十名，使用同一份公开快照、月份筛选与排序函数，每座城市只出现一次。当前视角为`month=10&season=2026-10`。编辑短评只解释城市，不决定次序。表格使用GitHub支持的HTML单元格，手机保持完整行并在表格内横向滚动，避免中文城市名和签证竖排。

国内另列综合前五，不限定出发月份，链接为`?country=CN`。推荐月份按目录标签合并连续区间，气温仍显示本期月份；上海暂无这一统计期的均温，保留“—”。其余九座国内目的地提供资料入口与已知气温，不填月预算和名次。

需求速查表把六种常见条件放在一起，每行列出对应网页结果的前三名与总数：月预算不超过1,000美元、免签且不超过1,000美元、国外网络优先、国外安全优先、当月18–28°C，以及提前看1月避寒。前五行沿用本期月份，最后一行明确改为1月；网络与安全展示的是原评分/10。相同城市可能符合多个需求，因此会在分类中再次出现。每个“更多”链接带上完整筛选条件，前三名不另做去重或人工换位。

默认Metric Score保留原始综合分。省钱、网速、安全预设的主指标各占50%，省钱和网速两组另有25%的安全权重。个性化花费依据参考金额连续换算，避免整数分档把不同消费水平并为同分。签证免签属于筛选条件，不加入分数。公式与回归记录见[榜单复核](seasonal-ranking-2026-10.md)。

明确的暂勿前往提醒先于权重生效，当前维护7座目录城市的排除记录，见[推荐资格与官方来源](recommendation-policy.md)。该记录尚未覆盖全球全部旅行风险。取消当期视角会回到普通月份排行，通用出行排除项仍然保留。

## 表格里的数值

| 字段 | 来源与含义 |
| --- | --- |
| 月花费 / USD | 城市目录中的历史月参考金额，取整显示。房型与包含项未统一，不能视为今天可订的报价或最低生活门槛。 |
| 月均温 | 2023–2025年ERA5历史重分析，按城市坐标取值并四舍五入至整数；不是出发日天气预报。各国气象站常年值另留在城市资料中，不混写成同一统计期。 |
| 大陆护照 | 目录入境标签。入境资格、停留期与远程工作许可分别核实，个人居住地和职业也可能影响申请。 |
| 为什么这个月去 | 不超过25字的编辑建议，包含具名地点、设施或对应城市数值。文案中的气候和消费数字也来自本期快照。 |

安全和网络仍为资料中的评分；网络不是实测Mbps，安全分不能代表每个街区。缺失值保持为空，不补成零分或猜测价格。

目前目录有350座城市、258个国家与地区条目，224城有完整六项历史评分。国内收录14座，其中5座有完整评分。目录收录与实际研究覆盖分开。所有城市照片为真实照片，作者与适用许可见[署名记录](../CREDITS.md)。

## 消费分项怎样使用

城市消费分项来自CostCompass，日本e-Stat保存全国单身家庭统计，汇率采用ECB同一发布日交叉参考值。这些观察保留原币、单位、日期与来源，不能直接替换成某城游客短租的总生活成本。全国居民住房支出也不是东京整租报价。

按住房、餐食、交通和工位分别估算，再加往返交通与应急金。网页支持填自己的单价、换币种和算天数。消费按每月15日的受控流程更新；全量云端月更当前尚未启用。见[消费来源说明](cost-sources.md)。

## 本期短评与来源

本期十城均包含在已研究的16城资料中。16城做过Web、Reddit、X和小红书定向检索，但并非四个平台的正文都已读到。Web和Reddit每城读到正文，X为4城、小红书为3城读到发布文字；搜索摘要、原帖和部分评论分别记录，不把读到文字等同于看过图片或视频。

本次为README补读了[安塔利亚官方老城介绍](https://goturkiye.com/antalya/see)和[拉斯坎特拉斯官方海滩介绍](https://www.hellocanaryislands.com/beaches/gran-canaria/las-canteras-beach/)，用于具名地点短评，读取日期为2026-10-18。Outpost通话设施依据[运营方说明](https://destinationoutpost.co/cowork-in-ubud/)，华强北硬件供应链依据[福田政府报道](https://www.szft.gov.cn/ftxx/xwdt/ftdt/content/post_12972999.html)，博卡拉秋季湖景依据[尼泊尔旅游局](https://ntb.gov.np/en/the-beauty-of-pokhara-in-autumn)，费特希耶海岸依据[土耳其官方秋季指南](https://goturkiye.com/branding/press-releases/summer-continues-in-the-turkish-riviera-and-the-turkaegean)。

这些地点与季节建议不保证每个房间的网络、实时空位或当天景观。逐条发布日期、读取范围与访问限制保存在[季节研究记录](../data/seasonal-2026-10.json)和[README编辑记录](../data/readme-2026-10.json)；也可阅读[逐城来源](../../guides/seasonal-2026-10.md)。

新增的国内与需求表只展示目录数据，不为新出现的城市补写四平台体验短评。免签且低预算一行出现的摩洛哥入境标签，另核对了[驻摩洛哥使馆2025年7月领事提醒](https://ma.china-embassy.gov.cn/lsfw/zytz/202507/t20250716_11671271.htm)；90天免签与工作许可仍需分别判断。README的27座不同城市包含资料入口，不等于27座都完成了本期十城的短评研究。

## 订整月之前

1. 首周选可取消的住宿，试一次真实会议，检查房间安静程度与手机热点。
2. 在实际开会时段试工位，问清通话间、夜间权限和停电安排。
3. 按自己的护照和工作方式核实手续，免签入境与工作许可分别判断。

## 每期怎样更新

在`web/`运行`npm run seasonal:readme`，只替换README的主表、国内推荐、需求分类和“本期变化”四个标记区块；介绍、脚注和本地运行说明保持原样。`npm run seasonal:readme -- --check`只检查，不写文件。

本期短评与更新条目存放于`web/data/readme-2026-10.json`。生成时检查十城唯一、五列齐全、文案不超过25字、禁用词以及来源对应关系。首选短评不合格时自动使用同城已编写的备用短评；全部不合格就停止写入，等待重写，不裁掉限定词或编造事实。“本期变化”只描述实现中可验证的更新，记录日期必须属于本期，不填虚构的新增城市或涨跌。

国内与需求表由`web/scripts/readme-discovery.mjs`使用网页同一排序函数生成，测试核对每行城市、权重、筛选与总数的链接还原结果。缺失的国内均温显示“—”；没有评分的目的地始终只作资料入口。若某分类不足三城，或国内不足五座完整评分城市，停止生成并要求复核，不凑数。

换期需更新月份定义与研究资料，补足新入榜城市的短评。机械检查能发现格式和数据漂移，具体说法是否值得推荐仍需编辑判断。
