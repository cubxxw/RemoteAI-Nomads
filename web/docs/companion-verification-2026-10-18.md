# 小狐旅伴验收 · 2026-10-18

本轮交付是全站右下角的小狐狸入口、轻量对话窗与本机历史。模型仍为 DeepSeek Flash，城市数据仍在 D1；没有开通付费 Workers 或部署容器。

## 证据边界

浏览器操作使用 gstack browse。使用真实浏览器 IndexedDB 检查持久化，没有把内存桩当成本机保存。自动测试共178项通过，其中会话/存储16项；另有排行缓存与免费额度错误处理回归测试。

真实 DeepSeek Flash 在临时 localhost:8791 验收服务完成一轮气候查询：使用同一份只读公开 SQLite 发布快照、原生工具循环与正式前端，9.5秒完成，读取1次真实工具。回答给出清迈1月历史均温22.3°C、2023–2025数据区间及可点开的来源。此测试没有模拟模型，但运行位置是本机，不能冒充线上 D1 验收。

线上浏览器确认小狐已发布，之后新提问在 D1 admission 读取阶段返回503。运维追踪确认原因为 Cloudflare 账号当日 D1 免费读取额度耗尽，不是 DeepSeek 密钥、余额或模型故障。服务方提示UTC午夜重置，即北京时间2026-10-19 08:00。已将公开错误改成明确原因、重置时间与本机历史仍可查看的说明，并附 Retry-After；新提问的线上成功验收仍待额度重置。

## 状态与隐私

只保存可见问答、引用、预算选择与草稿；字段允许列表剔除密钥、隐藏推理和服务器审计内容。写入失败明确提示导出，不假称保存成功。删除失败恢复当前状态。收起与停止分开，恢复历史不触发模型，不展示隐藏推理。清理当前浏览器数据会删除历史，不跨设备同步。

默认静坐，无声音、循环跳动、自动发问或红点催促。悬停为轻微姿态回应；思考与完成各有表情；尊重减少动态效果。手机窗使用visualViewport高度、宽度和偏移适配可见区域。

## D1重复读取修正

正式公开排行目录按站点和发布版本缓存五分钟，并合并同时发生的读取；发布版本变化立即换缓存，失败读取不缓存，调用者得到独立副本。私人预览不进入缓存。回归测试确认两次并发读取从6条目录查询减少为3条，后续同版本读取复用结果。此修改减少未来重复消耗，不会恢复已经用完的当日额度。

本轮没有重跑完整30题模型质量评测；吉祥物与历史功能不能证明旅行建议达到95分或审美达到98分。
