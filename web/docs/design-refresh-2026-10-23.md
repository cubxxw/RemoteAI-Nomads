# 2026-10-23 网站设计与配图改版

本轮从 `ca4584e` 改进 Roamorrow Nomads 的城市发现、指南入口与共享界面。目标是让中文远程工作者看见目的地，同时能读清预算、月份和停留条件。验证使用隔离的公开演示数据，不连接生产 D1，不调用模型；以下证据是本地实现验收，不表示正式网站已经发布。

## 设计选择

比较了两个可运行原型：[A 编辑式发现](images/design-refresh-2026-10-23/prototype-a-desktop.jpg)、[B 选择工作台](images/design-refresh-2026-10-23/prototype-b-desktop.jpg)。采用 A 的照片叙事和 B 的选择控件；正式版缩短原型的 hero，保持“开始选城”和实际筛选入口可见。

- 日光白纸面与森林绿强调色，沿用已有品牌和导航。
- 首页以虚构工作场景引入，结果使用真实城市大图；桌面三列、平板两列、手机一列。
- 每张卡片直接显示历史月参考、综合分、安全、所选月份舒适度、网络指标、月份带和大陆护照标签。简介保留两行高度，指标标签撤销旧表格的隐藏样式。
- 改条件后压缩 hero，使搜索结果上移。地图只按用户明确开关及其本机偏好恢复。
- 指南索引增加封面和可滚动的手机专题导航；无具名城市文章使用场景插图。15 篇独立预算指南在响应时补入其城市照片与署名。
- 统一按钮、焦点、边框、留白及空状态；中文标题按完整短语换行。

## 图片与来源

三幅写实场景由内置 OpenAI imagegen 于 2026-10-23 生成：山湖露台、海岸咖啡馆、街区咖啡馆。每幅有 1440×960 与 720×480 两档 WebP，六个文件共约 0.91 MiB。按 2026-10-26 的展示要求，首页、专题卡片和指南封面移除创作方式标签；替代文字描述画面并注明“场景示意”，不作为任何城市、店铺或现场体验的证据。[资产清单](../data/editorial-images.json)保留工具、场景、用途和尺寸。上方截图记录的是 2026-10-23 的界面。

350 城照片沿用现有真实照片。指南封面仅取文章涉及城市的公开照片，并链接原署名来源；未改动预算、签证或评分。图库在源码中的名称、许可和来源与公开数据库核对一致。

首屏 hero 使用高优先级加载，下方城市卡和专题延迟加载。独立预算指南新增的首图同样优先加载。所有新增图片带尺寸；失败后显示城市名和“城市图像待补”，不会替换成其他地点。场景插图失败时显示场景名称和“场景图片待补”。

## 实现与边界

- `editorial.css` 是共享界面的最终样式层，`guide-runtime.css` 对独立批准文章只作附加调整。
- `mountMarkup` 和 `relocatePublishedHTML` 均逐项改写响应式 `srcset/imagesrcset`；普通请求和公开备用页面均正确挂载在 `/nomads`，兼容旧挂载路径。
- 文档级图片失败监听同时处理新错误与模块安装前已失败的图片，跳过未加载的 lazy 图片；一次替换后不再请求失败地址。独立文章只加载轻量 `guide-visuals.js`，不引入整个应用脚本。
- 对比选择器换城清除旧 `srcset`，可从失败占位恢复。排行仍使用同一 SSR/动态模板与更新钩子，网格重排计算 X/Y 位移；删除失去祖先样式的 ghost 动效。保留 reduced-motion 分支。
- 路由、筛选/排序公式、URL 状态、本机收藏/对比、助手草稿与历史、模型权限及限额未变；未发送模型请求、消息或价格更正。
- 公开备用页面从审核后的演示数据库生成，目标 `https://roamorrow.com/nomads`；保留原数据日期与停留限制。

## 基线图片指纹修复

基线包含 ImgBot 提交 `a8ae7d6`：它改写了已批准 JPG 的字节，但批准回执仍绑定旧散列，导致指南与对比发布校验失败。本轮恢复24张图片为 `a8ae7d6^` 的已批准字节：11份指南源资产及其11份公开副本、2份对比社交卡。不修改批准回执、指纹或校验规则。

独立核对全部76份指南资产及公开副本、65篇批准源稿、17份对比文件/资产均匹配回执。其他 ImgBot 图标压缩保持不动。此修复用于让既有发布门禁重新成立，不是重新批准文章或更新价格。
