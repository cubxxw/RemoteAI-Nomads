# 结果在前的城市选择体验

本轮按实际任务验收：找城、改变视角、查看一城、两城比较、准备出发。首页保留高密度列表与地图，配置按“预设 → 条件 → 权重”展开。内容页共用容器、字体、色彩与操作语法；少量内容用重点展示，不用空格填满模板。

## 验收依据

| 维度 | 可核对的结果 |
| --- | --- |
| 首页层级 | 1440px 下首条城市顶部不超过 260px；权重默认隐藏；当前视角与结果数清楚 |
| 渐进披露 | 常见预设一步完成；筛选可增删；权重抽屉实时更新；关闭后焦点返回 |
| 状态恢复 | 显式 URL 优先于本地偏好；刷新、浏览器返回、撤销和重置符合预期 |
| 键盘与触控 | 命令面板搜索和选择；/、J/K、Esc；390px 完整导航；主要操作可触达 |
| 视觉系统 | 1200px 共享容器与响应式边距；400/500/600 字重；内容高于配置；全站页脚不裁切 |
| 内容结构 | 国家按大洲浏览；一城国家有重点；单篇指南可直接阅读；对比能逐项看差异 |
| 数据诚实 | 缺失保留缺失；历史价格有口径；签证旧标签不变成实时承诺；预览禁止索引 |
| 真实渲染 | 桌面、平板、手机及窄屏无页面横向溢出；可见实景图加载；无脚本异常 |

截图与浏览器采样保存在 `.data/ux-redesign-2026-10-18/`。通过率只表示已测项目的通过率。审美分是设计审查判断，不等于真实用户满意度，也不能代替真实手机与用户研究。

## 交付记录

本轮由三位实现代理分别处理首页、公共视觉和内容页，一位未参与实现的代理独立审查；主代理集成对比页，亲自查看截图、执行双引擎任务流并裁决退回项。本地预览已更新，没有发布到公网。

### 首页与全站变化

首页采用当前视角、预设、筛选浮层、权重抽屉四个清楚的层次。六项权重默认隐藏；手机面板保留随权重改变的前三名和名次变化，滑块区域独立滚动。地图在桌面原地展开为300px，手机使用可关闭的底部面板，定位后返回对应城市。命令面板支持中文输入与城市跳转，分享、撤销、重置及本地恢复均可用。

桌面首城从 **517.8px 提前到251px**；390px手机从 **495.2px 提前到241px**。公共容器、主标题、字体、颜色、SVG图标、完整手机导航和页脚统一。桌面指南短页页脚底部为900px，与测试视口底部一致。

城市页将预算计算器放在分项价格之前，住房仅默认显示两条，其他消费类别和日本全国统计按需展开。国家目录按大洲浏览，支持城市覆盖筛选和常用国家别名。单城国家采用两栏重点展示，零城市有明确空态。指南提供可保存的三步清单。双城对比标明差额、支持月份切换，并保留历史估算和政策口径。

内容类型最终独立评分：首页96、城市95、对比96、国家目录95、国家内容95、指南96、公共导航与页脚97。尚未给满分的原因是部分城市摘要仍通用、国家官方长名称偏长、历史与缺失数据会影响选择信心；还缺真实手机和用户理解测试。继续提升应投入内容准确度与真实观察，不再增加装饰控件。

### 退回项及处理

| 发现 | 处理与复核 |
| --- | --- |
| 东京手机预算输入埋到页面2786px | 计算器移到明细之前；点击生活预算后，三输入分别位于375/437/499px |
| 手机权重面板遮住全部城市 | 固定实时前三名和升降预览；390×667下预览与完成按钮可见，中间可滚动 |
| WebKit原生筛选框仅22px高 | 显式44px高度并统一外观，实际测量四个框均为44px |
| 指南拆开“一周”，空态有孤字 | 语义不换行组、横向三步与独立进度行，短空态标题；320px复核 |
| 韩国、英国、美国与常用英文名称检索不到 | 新增34个地区的共享别名词汇，首页、命令与国家目录一致使用 |
| UK/US子串混入乌克兰、澳大利亚或历史地区 | 已识别缩写按地区代码匹配；无代码历史项不进入代码结果 |
| 分享剪贴板不可用时出现旧式小方框 | 手工复制回退使用同一对话框样式、48px输入框与复制指引 |

### 实测证据

- 110项单元及回归测试通过，构建预检通过。
- Chromium 155.0.8059.80与WebKit 27.2各完成30项实际任务流，包含中文输入、历史往返、存储恢复、手机实时排名预览、预算计算和对比月份分享；没有页面脚本异常。
- 13类路由×4种宽度，共52次页面检查；320/390/768/1440px无页面横向溢出、可见图片加载失败。正常路由返回200，未知路由保留真实404。
- 桌面与手机的26个完整页面检查、13个展开状态检查均未发现自动可访问性违规。另验证了触控模拟与浏览器存储禁用；这些不能替代真实设备和屏幕阅读器测试。
- 10个中英文国家查询，在目录、首页与命令三个入口实测。中文“美国”可同时显示美国本土外小岛屿这个相关目录项；代码US只显示美国。
- 真实本地D1的348座城市服务端渲染通过，外键问题为0；默认224座完整指标城市的分数逐条保持一致，草稿发布边界继续有效。
