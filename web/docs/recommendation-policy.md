# 推荐资格与出行提醒

低参考消费不能抵消明确的暂勿前往提醒。排行先应用已核读的出行排除规则，再按用户偏好计分；省钱、网速和安全三种预设的主指标各占50%。省钱和网速两组另保留25%的旧安全评分权重。

这套规则面向中国大陆普通护照的一般出发者，属于本站推荐判断，不是法律禁令。它只覆盖下面已核读的提醒，**没有完成全球安全审查，入榜也不等于安全保证**。旧安全分缺少统一的实时校准，不能用一个分数阈值代替官方提醒。

## 在产品中怎样生效

所有推荐排行共用同一个入口，包括首页、城市排行、国外/国内范围、任意月份、服务端首屏、数据库故障时的公开快照，以及AI的城市推荐工具。切换预设、开启待补资料，或手动把花费拉到100%，都不会取消已核读的排除项。

原目录、国家页和城市资料仍保留。被排除的城市页展示提醒与官方来源，对比页说明其暂不作为出发推荐。AI直接查询城市时返回资料、排除原因和来源；推荐查询不会用低价把它重新排入结果。覆盖统计分别提供原始指标完整数和可参与推荐数。

旧分享链接、本地偏好中的三种80%预设，会迁移为当前50%预设。其他手动权重继续保留，出行排除规则独立生效。默认Metric Score和历史原始评分保持不变，个性化花费继续按旧参考金额连续计分。
