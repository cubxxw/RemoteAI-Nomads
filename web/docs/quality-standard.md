# 四方向质量标准

依次完成：数据库与首页排行 → 实时权重与筛选 → 统一视觉 → 动效、键盘、触控和对比。

每方向满分100，98为目标。一项关键功能失败，就判该方向未达98，不用其他漂亮分数抵消。未测不能给满分。工程可按清单评分；视觉包含设计判断；真实理解效率和满意度需要用户研究，必须区别记录。

| 方向 | 标准 | 关键失败 |
| --- | --- | --- |
| 首页 | 首屏直接决策，默认分一致，数字对齐，地图真实联动 | 宣传首屏、缺失补0、假地图 |
| 权重 | 六项实时重排、预设可解释、URL往返与返回键一致 | 只改控件、不改排名，分享丢状态 |
| 视觉 | 中性灰+强调色，4/8间距，字体/数字系统，无装饰噪声 | 低对比、数据遮挡、手机裁切 |
| 细节 | 150–250ms可中断动画，减少动态效果，键盘、触控、恢复、逐项比较 | 焦点丢失、滚动劫持、凭空胜负 |

## 本轮评分方法

每方向把产品正确性、可发现性、响应、可访问性和视觉一致性合并审查；关键失败优先，不能用平均数掩盖。评分是有证据边界的设计判断，允许保留缺口，不将测试通过率等同体验得分。

首页与数据看排序是否诚实、同一视图能否比较关键事实、地图是否表达同一城市；权重看改变偏好后结果是否随之改变，以及能否分享、返回、恢复；视觉看信息层级、对齐、对比、密度和手机发现性；细节看中断后连续性、焦点、输入法、触控替代和错误恢复。参照站点提供审美方向，不能作为自动抄袭的模板。

98以上的额外门槛：已发现的严重功能问题全部解决；代表性设备与浏览器实测；至少验证用户能完成找城、调权重、解释排名、分享和双城比较；不得靠缺失资料或未测试项获得满分。目前工程交互可检查的门槛通过，但完整数据、真实设备与用户理解验证尚未完成，因此不能宣布所有维度超过98。
