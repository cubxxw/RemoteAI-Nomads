# 2026年10月榜单与偏好排序复核

本期README展示五组各五城，合并后13城；研究记录保留已核读的16城。它与网站使用同一份公开城市快照、月份筛选和排序函数，编辑短评不决定入榜次序。

## 偏好权重与花费计分

省钱、网速和安全预设的主指标各占50%，其余合计50%。省钱和网速两组保留25%的旧安全评分权重。原80%预设挤压了其他指标，现已降低；旧链接与本地保存的三种原预设同步迁移，其他手动权重不变。

旧花费评分按整数分档，450美元与700多美元的月参考可能同为10分。个性化花费分现按旧月参考连续换算：300美元为10分，每翻倍减2.5分，限定0–10；缺金额不推测便宜。先用未舍入分数排序，显示时才保留一位小数。省钱前五为博卡拉450、成都730、乌布800、杭州950、撒马尔罕720美元/月，其他50%的指标仍参与排序。

这套编辑归一化规则没有证明300美元足够生活，也没有统一各城旧参考的房型与包含项。默认Metric Score保留原分；自定义分与原分不能直接当作同一统计量比较。网络仍为旧评分，不是Mbps。签证友好采用免签标签筛选，再按综合分排序，入境与工作许可分别核实。

## 推荐资格先于计分

阿富汗原来只在十月出发视角排除，普通省钱榜仍会纳入。现在所有排行先应用[已核读出行排除规则](recommendation-policy.md)，再计算权重，任意月份、国外筛选、手动100%花费和待补资料开关均适用。城市历史资料保留，直接查询和对比会显示提醒。该规则只覆盖已核读来源，不代表已完成全球风险审查。

`month=10&season=2026-10`另表示本期大陆普通护照出发视角，赴日提醒与通行条件见[本期指南](../../guides/seasonal-2026-10.md)。改月份会移除当期筛选，上述通用出行排除规则仍保留。

## 当季短评与来源

16城均检索Web、Reddit、X、小红书。Web与Reddit每城都读到正文；X为4城、小红书为3城读到发布文字。其他结果保留检索或访问受限状态，没有当作原帖事实。原帖文字不等于图片、视频或完整评论已读；具体来源、时间与限制保存在公开研究记录。

城市页用简短的当季观察替换本期城市原来的泛泛介绍，来源按需展开。未研究的城市不套用别处短评，消费、气候和入境的原记录分别保留。

## 维护与验证

在`web/`中运行`npm run seasonal:readme`，按网站规则更新README区块；`npm run seasonal:readme -- --check`检查漂移。换期需要重新核读、补齐新入榜城市并显式更新本期定义，不能把十月判断自动当成十一月建议。

回归检查覆盖主指标权重、连续花费、默认原分、旧预设迁移、五组链接与README一致、研究来源、出行排除范围、所有月份、服务端首屏和AI工具。检查不调用付费模型。

## 快捷范围与行内导航

排行常驻“全球、亚洲、国内、国外、本月推荐”。范围与月份可以叠加，再点已选标签即可取消；快捷标签已表达的条件不会重复显示。国内使用`country=CN`；国外使用`abroad=1`，排除中国大陆与港澳台条目。国内与国外互斥，切换范围保留权重，国内会清除冲突的境外入境筛选。

本月按新加坡时区取月份，依据原推荐标签筛选，不代表本月天气预测，也不自动套用某一期编辑判断。分享、本地保存与服务端首屏采用相同规则。

国家名和旗帜共用国家页链接，键盘可直接访问。点城市行其余区域进入城市页，国家链接和对比按钮各自操作；拖选文字不触发导航。指标使用等宽数字，字号高于单位说明；月份带只保留1、6、12三个刻度，当前月份用条形轮廓标明。
