# 2026年10月榜单与偏好排序复核

本期 README 展示五组各五城，合并后16城。它与网站使用同一份公开城市快照、月份筛选和排序函数，编辑短评不决定入榜次序。

## 为什么省钱组现在更便宜

旧花费评分按整数分档，450美元与700多美元的月参考可能同为10分。原排序又先四舍五入，再按原综合分排并列，会减弱用户选的偏好。

省钱、网速、安全预设现在分别将主指标设为80%，其余合计20%。自定义花费分依据旧月参考美元金额连续换算：300美元为10分，每翻倍减2.5分，限定0–10；缺金额不推测便宜。先用未舍入分数排序，显示时才保留一位小数。

这仍是编辑归一化规则，没有证明300美元足够生活，也没有统一各城旧参考的房型与包含项。默认 Metric Score 保留原分；切换自定义口径后显示“自定义分”，两者不能直接当成同一统计量比较。签证属于资格条件，采用免签标签筛选，再按综合分排序。

省钱前五为博卡拉450、拉巴斯480、成都730、撒马尔罕720、河内740美元/月，均为旧参考。余下20%仍参与排序，因此不会严格按金额升序。

## 本期筛选和来源

`month=10&season=2026-10` 表示本期大陆普通护照出发视角。已核读的出行提醒与通行限制、移除方式见[本期指南](../../guides/seasonal-2026-10.md)。它不是全目录风险审查，也不覆盖其他月份；改月份后自动移除本期建议。

16城均检索 Web、Reddit、X、小红书。Web与Reddit每城都读到正文；X为4城、小红书为3城读到发布文字。其他结果保留检索或访问受限状态，没有当作原帖事实。原帖文字不等于图片、视频或完整评论已读；具体来源、时间与限制保存在公开研究记录。

城市页用简短的当季观察替换本期城市原来的泛泛介绍，来源按需展开。未研究的城市不套用别处短评，消费、气候和入境的原记录分别保留。

## 维护与验证

在 `web/` 中运行 `npm run seasonal:readme`，按网站规则更新 README 区块；`npm run seasonal:readme -- --check` 只检查漂移。换期需要重新核读、补齐新入榜城市并显式更新本期定义，不能把十月判断自动当成十一月建议。

本轮完整检查215项通过。回归覆盖默认原分、80%主指标、缺金额、舍入并列、五组链接与README一致、16城来源锚点、月份变更、本地保存，以及数据库故障时服务端直接还原五组排行与控件。检查不调用模型。

本机使用实际浏览器验证了390宽手机与1440宽桌面：省钱前五、预设选中、来源展开、命令面板改月份和无横向溢出。发现并修复手机搜索表单旧排序样式导致的助手入口重叠。

## 快捷范围与行内导航

排行常驻“全球、亚洲、国内、本月推荐”。范围与月份可以叠加，再点已选标签即可取消；快捷标签已表达的条件不会重复显示一枚筛选标签。国内使用 `country=CN` 匹配真实国家代码，切换范围保留排序权重；改为国内会清除冲突的境外入境筛选。本月按新加坡时区取月份，依据原推荐标签筛选，不代表本月天气预测，也不自动套用某一期编辑排除规则。

国家名和旗帜共用国家页链接，键盘可直接访问。点城市行其余区域进入城市页，国家链接和对比按钮各自操作；拖选文字不触发导航。指标数字使用等宽数字特性，字号高于单位说明；月份带只保留1、6、12三个刻度，当前月份用条形轮廓标明，避免数字挤在一起。

新增回归覆盖国内筛选、本月跨时区边界、分享和本地恢复、数据库故障时的首屏。完整检查219项通过；实际浏览器另验证整行跳转、国家链接、对比按钮、返回与刷新恢复，以及390宽手机排版。
