# 分享图片与验收

分享采用「旅行编辑手记」：真实地点、清楚的中文标题、少量关键数据。图片负责让人读懂，配文保留完整范围和来源，链接负责继续核对。延续现有字体、奶油纸色、深棕与城市摄影，不把整个页面截图后发出去。

## 已接入的内容

排行视角、排行中的单城、城市详情、公共双城对比、明确选择的个人方案、对比托盘中的城市、指南及预算计算器、第一周清单、国家与城市目录、方法页、工作地图中的地点，以及已完成的单条回答。回答只分享所选正文和引用，支持删减图片正文；没有公开会话链接就不生成会话二维码。

统一面板以实际导出预览为主，只有一处实心「保存图片」；其下是「复制链接 · 系统分享」。配文常显可编辑、复制，完整链接不单独占据默认界面；浏览器拒绝自动复制时，显示可选中的链接。长内容分页，并可整组下载。系统取消是正常退出，不会自动下载、再次弹出或替用户发布。

面板通过「竖图／文字版」分段切换，两者均为1080×1440。文字版去掉照片，保留相同的数据与顺序。分辨率只作说明，切换不改已编辑的配文。以下五种底层比例继续用于图片渲染与回归评估。

| 图片预设 | 尺寸 | 建议用途 |
| --- | --- | --- |
| 编辑竖图 | 1080×1440 | 小红书、微信聊天 |
| 通用方图 | 1080×1080 | 朋友圈、群聊 |
| 信息流 | 1080×1350 | Instagram、LinkedIn 图片帖子 |
| 横向卡片 | 1200×630 | 链接预览、横图 |
| 全屏竖图 | 1080×1920 | Story、状态 |

这些是本产品的导出预设，不是对每个平台接口或接收效果的保证。图片原图、配文和文件出口保留，系统能力不足时仍能完成分享。

## 内容边界

月份固定为此次实际视角；币种、历史口径、核对日期和缺项跟随数据。图片生成时间不冒充价格日期。比较中的官方暂勿前往提醒也必须保留。

城市手记的眉题注明所选月份，已有标签最多三枚；历史月花费、该月历史均温、入境或入住标签、旧网络评分按2×2排列。缺项显示「待补充」，真实零分保留为零。数据日期、历史口径和待复核标记紧随各自指标。普通说明完整保存在配文中，页脚只留短链与二维码；有明确官方出行提醒时，在每一张图片的标题后保留该提醒，续页也不例外。

普通分享不带个人报价、会议、草稿和完整对话。城市及比较可明确选择包含自己的方案，指南可明确选择包含手填房租；这些金额进入图片与配文，公开链接仍只恢复公共资料或公开计算选项。清单进度同样需要明确选择。

预算指南按公开选项重新计算默认分享金额，避免从页面里截出已经混入个人房租的总额。图片只保留当前情景和关键费用限制；完整警告、押金说明、汇率/舍入口径与原文摘要都保存在配文中。不会把30晚原文摘要里的金额放在31晚图片里当作同一个数字。

原批准指南的 HTML、资源和批准指纹不改。分享按钮与准备状态通过响应时增强接入；旧“复制预算”入口也进入新面板。在安全处理器准备好之前，按钮保持不可用并说明原因。

图面不印来源提示、照片署名、许可证或脱离指标的日期；这些信息保留在配文、展开详情与原页。长署名不再影响照片显示。照片失败可重试或选择文字版，不替换成别的地点。二维码编码同一完整公开链接，长筛选链接会获得更大的二维码和相应版式空间。

## Eval 的使用

`npm run evals:share` 执行固定公开样本与保守排版检查，输出到 `.data/share-eval/results.json`。该测量用于回归，不代替真实字体或图片验收。

`npm run evals:share:browser` 在本机9017端口提供实际浏览器评估。点击运行后导出39个样本的五种比例，包含缺失资料、长中文标题、长摄影署名、官方提醒、旺季预算及100字中文搜索。可下载原始图片、结果和默认链接图。图册使用延迟加载，避免同时解码几百张大图。服务仅绑定127.0.0.1，不在部署资产目录。

结果绑定源码提交、分享模块/数据指纹、浏览器版本、时间、实际尺寸、字节数、分页和耗时。保留失败批次及修复后的新批次，不用后来的成功覆盖原始失败。

`npm run evals:share:release -- --review=/绝对路径/分享评审.json` 检查正式门槛；可从 `evals/share-review.template.json` 开始。证据路径相对评审文件解析，必须真实存在。

八个维度分别至少97，不能取平均抵消：内容覆盖、准确、隐私、便捷、理解、视觉、平台、稳定与可访问。关键失败直接不通过。阅读和视觉必须有目标用户证据，平台必须有实际接收记录；普通测试或维护者自评不能代替这些证据。未测为 null，正式门槛返回失败。

目标用户研究采用至少8位有旅居/远程工作及实际资料分享经验的中文用户，盲序看同内容版本。先做地点、金额、月份、限制和继续核对路径的理解题，再评价阅读和视觉，记录首次结果、重试、评分分布和原话。模拟角色与维护者判断分别标注，不计作真实受试者。
