## 数据库实读

20张业务关系表。258个地区（250标准目录+8历史保留）、348城、348条评分投影、348条大陆护照条件、339个位置、1896条气候月记录（158城）、1篇普通文本候选、13城照片。城市全部未发布。

原有4176月标签、750条AI地域、23条人工核读规则、97条第三方政策、15条工位报价、1750条统计观测均保留。统计含351缺失；没有读取或导入私人Notes。

只读实际Wrangler本地数据库：SQLite完整性ok，外键错误0，文件4,165,632字节，约4MB。`scripts/validate-local.mjs` 检查348城详情与9个主要入口、默认分逐条一致、比较URL308归一、真实404和草稿生产隔离。它不写数据库。

坐标按同国家名称/别名匹配，歧义与复合地点留空；没有把首都复制给其他城市。历史气象来自ERA5 2023–2025网格重分析，不是当前预报或30年气候常态。来源限流已停止新增请求，缓存留存，缺口未造值。图片与字体许可见CREDITS.md。

## 浏览器实测与修复

独立审查最初发现三项重要问题：慢速输入New York会吞空格；拖动地图后点选失效；地图高亮重挂节点导致键盘焦点丢失。三项均已修复并分别由独立浏览器复测。另补中文composition保护、地图重建保焦、Esc清除选择、月份变化后避寒预设不再误亮。

真实浏览器验证：/聚焦、J/K选城、滑块键盘End改变分数、地图方向键与Enter定位、动态新增80行后的对比按钮、浏览器历史往返、分享、空态和清除。中文组合输入通过模拟composition事件验证，未宣称已驱动实体中文输入法。

320、390、768、1440、1600均无页面横向溢出。手机预算/签证分行可见，权重首屏直接折叠；地图按钮移至地理区域下方，避免遮住日本。小点另有22px近点选中与44px原生选择器。比较两列在390下同时可见，不给缺失/持平/签证判赢家。

首页与比较的axe WCAG A/AA、2.1 AA和best-practice检查零违规；新增城市气候表后城市详情同样零违规，并修复600px表格将手机整页撑宽的问题。地图网络失败测试保留40行，点击重试后成功加载；这次人为断网产生的控制台请求错误属于预期，正常浏览未见页面脚本错误。

本机桌面一次导航：LCP约140ms、CLS约0.000036、无长任务；手机折叠修复后CLS=0。这些是localhost、单会话数据，不能代表公网Core Web Vitals。紧凑月份传输将HTML从747,285减至523,053字节（未压缩）。正式Cloudflare传输与弱网/CPU节流尚未测。

`npm run check`、`node scripts/validate-local.mjs`、`npm run build`均通过。构建为dry-run，Worker约62KB/gzip19KB，不等于正式部署。
