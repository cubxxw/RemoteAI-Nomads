# 原生 DeepSeek Flash 上线验收

2026-10-18。本轮采用 `deepseek-flash`，规划为 low 思考，分离核验为 none；两者均为 Flash。通过 Workers 原生 HTTP 调用，不部署容器、不部署个人 Codex 凭据。城市读取来自正式 D1；旧 DSH 与本机实验成绩不计入本轮。

## 验收标准与证据边界

真实线上测试经过公开域名、网关、会话对象、领域工具与生产 D1，使用运维私有入口验收。固定发布版本，记录测试前后 version_id；普通访问者不能读取完整评测证据。每题保存完整回答、工具证据、逐版核验与终态，仅在本机私有 `.data/flash-evals/` 中保存。

自动分由事实核验35、条件25、引用15、完成15、边界10组成；失败任务为0分。事实核验仍由另一次同模型调用执行，不能称作独立事实正确率或真实用户满意度。主代理与独立审查代理仍发现过自动100分回答中的交通范围错误，下面保留该证据。

## 已验证的工程行为

- 150项本地测试通过，包含实际 workerd/Miniflare 的 HTTP 调用兼容测试；fixture不消耗真实模型额度，不冒充线上回答。
- 主任务最多12次规划、6次核验、20次真实工具读取、180秒；软加权token额度只阻止后续调用，不保证固定金额封顶。
- 17类只读领域工具，无任意SQL、Shell、写库、私人Notion读取或任意网址访问。单次工具独立执行，避免长对话累积超出免费版50条D1查询限制。
- 真实线上9城详情连读完成；该路径原本合计超过50条SQL，隔离后正常运行。
- 上游模型中止、停止按钮、单独断连、跨会话不可读取/取消、普通访问不可读取评测证据均有真实测试。
- SSE按真实协议换行解析；合法Unicode段落分隔符不会截断JSON。评测增量保留run_id，并要求收到明确终态，不自动重试已经启动的付费请求。
- 引用统一为可点击的[E#]，括号形式也需通过本次证据归属校验。原始reasoning_content仅在服务端会话中回传模型，不写入日志或公开响应。
- 月均温不当作夜温或预报；降水不作为空气质量证据。14个正反配对测试（含预留金与费用分离）全部通过，属于受控语义材料测试。

最后一轮即使自动通过，也不等于语义完全正确：01把未确认的大交通直接排除；03把用户只排除的机票扩展至动车。两例已由独立审查发现，现加入窄范围预算检查：明确排除才允许、机票不等于动车、最新包含条件覆盖旧排除、提问与否定不当授权、未知价格不自动按零费用处理。它只覆盖已观察的中文句式，不冒充通用自然语言真值系统。

第二次完整32题固定版本 `nomads-939d064f18716ddd` / `c5278c2a-bebe-4007-89a8-5eb61a95669e`，证据 `2026-10-18T08-28-50-445Z`：28/32通过，均分87.5；核心26/30。没有超时或传输解析中断；2、3、7三题事实核验未通过，9题核验生成超限。并未达到95目标。

最终修正：规划保留low思考，Flash核验改为none，防止核验自身长时间生成；14项配对反例仍全部通过。事实不一致后使用新的Flash会话，依据用户问题与本次真实工具证据重写，不继续携带第一稿的隐藏推理。格式错误独立限3次，不占用事实核验的3次机会，总模型/工具额度保持原上限。预算范围检查另有7项边界回归，包括后续问题不撤销前句已确认条件、同一句最新包含条件覆盖先前排除。

固定最终重试实现 `nomads-496711a7426e80b6` / `ac154aa8-e722-4241-b7a1-7c6b619767d0` 的8题定向复测（1、2、3、7、9、14、31、32）自动8/8通过，耗时7.6–39.3秒。证据 `2026-10-18T08-39-58-754Z`。但是人工再次发现01仍把自设生活开销说成“整月不现实、只适合借宿”，说明自动100分仍有语义漏检。

因此发布版额外增加 `auditAffordability` 窄范围检查：样本没有证明全城最低价时，不接受已观察到的整月不可行/只能借宿等全局断言；具体方案的超支或指定房源超预算仍可保留。它有2项正反回归，不是任意自然语言推论的完整证明系统。最终公开版本及这一规则的实测在下方记录。

不能把不同版本的通过子集合并成一次满分，也没有把定向复测冒充新版完整30题。

## 仍需区分的边界

- 实际住宿供给、成交价和全城所有消费可能性未被穷举。工具能倒推若干生活方式的预算空间，不能证明某城绝无低价方案。
- 参考月成本、单项挂牌和全国住户消费不互相替代。未确认机票、押金和税费应保留待核项目。
- 同模型核验可能误放行或误拦；自动分不得包装成已经达到95分质量，视觉也没有宣称98分。
- 云端全量消费月更与每日FX未启用。本轮仅迁移并验收原生Flash助手。
- Workers/D1/SQLite Durable Objects有免费额度，DeepSeek API按量计费。本轮未开通新付费套餐。

2026-10-18，通过gstack browse的真实Headless Chrome 153执行，无运维或模型密钥进入浏览器。公开首页打开助手后，提问清迈1月气温/降水、夜温与空气质量边界，8.8秒完成、2次真实工具查询、5个可点击引文。点击E1后展开依据并聚焦对应来源组，包含ERA5原始接口与日期。
