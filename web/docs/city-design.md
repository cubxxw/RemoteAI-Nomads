# 城市页：一份可以拿来计划的目的地指南

城市页先回答「这个地方怎么样、花钱在哪、几月去、工作日怎么安排」，再提供可展开的来源。它沿用排行页的中性色与森林绿，不另起一套品牌。

页面从真实城市照片开始，接四项简明事实：本城消费样本数、原推荐月份、入境标签、当地时区。生活预算、出发季节、远程工作、停留入境使用页内导航，滚动时更新当前位置。桌面侧栏只保留城市自己的提醒和旅行小秘书入口；手机将提醒放在正文之后。

| 间距 | 4 / 8 px 网格；主段间隔 32 / 40 px |

设计中最醒目的部分是城市照片，其余地方让信息本身建立层级。首次审图后删去了城市页原有的统一提示块与大段说明。预算使用一块轻底色来表达可编辑区域；价格、气候和工位按内容排列，避免将它们做成同样大小的装饰卡片。

## 交互与证据边界

消费数据读取 `readCityCosts`。城市价格与全国单身家庭调查分开展示；商品价、票价、月租保持原单位，绝不自动相加为月总价。只有 CostCompass 的城市级一居室或三居室月租挂牌样本可以由用户主动填入月租；全国住房统计、其他来源、非月租、缺少挂牌标记或标记待复核的样本均不提供采用按钮。其他没有填写的预算项保持空值，并在结果旁说明未计入；填入 0 是用户明确的假设。

预算工具计算 `月租 × 天数 / 30 + 每日餐费 × 天数 + 其他月支出 × 天数 / 30`。用户切换人民币、美元、日元时，已填金额和参考价格随有来源的 ECB 汇率换算。没有汇率的原始报价保留原币。来源折叠区保留原币、单位、样本日期及旧月成本，旧数值不用于默认预算或最低门槛。

季节区域有全年均温曲线和月雨量柱。选择月份后，均温、降雨、季节标签和图中位置一起更新。缺失温度与真实 0 mm 降雨分别处理。源数据表、历史采样口径和来源放进原生展开控件。

会议工具以用户选择的上海会议日期和小时为起点，通过城市 IANA 时区计算当地时间，处理目的地夏令时和跨日。未记录时区时不猜测。AI 官方地域名单、工位报价限制和政策全文均按主题展开。旅行小秘书入口预填本城、当前月份、天数、币种及已填预算单位，空项明确尚未计入；用户确认发送才调用模型。预算和日历交互本身不触发模型。

标题、canonical、Place JSON-LD 和草稿 noindex 沿用现有外壳。没有 JavaScript 时，参考价格、默认月份气候、默认会议时差和原生来源展开仍可使用。

## 本地验收，2026-10-18

`node --test tests/city-page.test.js tests/render.test.js`：14 项通过，覆盖全国住房统计与待复核样本禁止采用、全国单位随币种正确展示、预算遗漏项、零值、缺失气候、币种方向、全国口径、跨季夏令时、跨日、日期无效、注入转义与 SEO。

使用隔离的 Playwright WebKit 浏览器完成真实页面验证，未占用共享桌面浏览器：

- 320 / 390 / 844 / 1440 px 无页面横向溢出；320 px 展开日本家庭支出和来源数据表后仍无页面横向溢出，表格在自己的区域滚动。
- 清迈租金样本填入，加餐费 100 CNY / 天、其他 600 CNY / 月，15 天结果为 3294 CNY；切换美元、日元后输入和结果联动。非法天数显示明确反馈。
- 1 月按「上一个月」回到 12 月；月份数值和图中高亮更新。
- 里斯本 2027-01-15 上海 09:00 对应当地 01:00；2027-07-15 对应 02:00。纽约同年 1 月上海 01:00 对应前日 12:00。
- 原生 WebKit 下拉控件原先实际只有约 25 px 高，已明确设置为 44 px，并实测全部可见城市表单控件和按钮均不低于 44 px。
- 禁用 JavaScript 后验证清迈价格、会议时间与来源展开可读。交互过程没有模型请求或页面脚本错误。

截图放在 `.data/new-city/`。它们记录本地预览，不代表已经部署，也不证明网络、住宿成交或个人签证资格。
