# 小狐：右下角的旅行伙伴

用户已选择小狐狸。沿用现有 Flash、领域工具与引用，新增可见入口、本机对话与历史，保留网页的灰绿配色、城市照片与信息密度。

比较了固定侧栏、悬浮小窗、动物入口加轻量对话窗。采用第三种：角色在右下角，默认只占约72px；桌面展开为440px宽、最多680px高的非模态窗口，页面仍能浏览。手机改为适应可见视口的模态面板。没有第二套聊天系统。

角色用四个一致造型：安静、好奇、思考、完成。暖色狐狸配森林绿围巾，环境仍是 #fafafa / #ffffff、#202323、#626767、#696f6f、#237a57 / #eef3f0。文字沿用Inter与中文系统字体；正文15px，标签12px，标题18px。动效160–220ms，状态变化才回应；不持续跳动，不弹催促消息，不自动调用模型。减少动态效果时静态切换。

窗口只保留角色名称、历史、新建和收起。欢迎区两个具体问题，点击只填入草稿；发送才查询。收起继续同一次任务，停止才中止；其他历史可以查看，当前运行固定在源会话，新的请求仍遵守后台单任务限制。切换不会串写答案或预算。

IndexedDB保存在当前浏览器，记录问题、展示答案、引用、预算选择及草稿。刷新/导航后可恢复，新窗口默认收起。上次pending标记中断，不自动重试计费。只带当前会话最近三轮与已选预算进入模型请求，不把整个历史上传。没有账号云同步；浏览器清理数据会删除本机记录，可主动导出。存储失败必须说明并保留当前页内容，不假装保存成功。删除独立会话可撤销。

验收：普通浏览器打开/恢复/历史导航没有answer请求；两会话互不串内容；真实答案刷新后引文仍能展开、预算选择保留；运行时收起继续，切换只更新源会话；停止有真实确认；中断恢复不重发；导出/删除/撤销/容量或存储失败清楚可恢复；1440、1280、390、横屏及减少动态效果可用，软键盘与对比托盘不遮控件。评分不以自报98代替实测。
