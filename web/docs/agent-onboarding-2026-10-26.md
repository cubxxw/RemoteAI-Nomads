# Agent 接入页

入口为主导航的「Agent 接入」，页面位于 `/nomads/developers/`。首屏提供公开 MCP 地址和问题示例，客户端配置按选择显示，Skill 安装和排错说明使用原生折叠区域。

页面沿用现有纸白与森林绿，以连接资料、提出问题两个区域组织操作。手机按顺序纵向排列，较窄桌面导航保留 GitHub 图标以容纳新入口。

接入页由纯渲染函数生成，不读取 D1，不发起模型调用，不进行浏览器端服务探测。链接指向已发布的 MCP 与 Skill 安装包。只复制示例，不会代用户提交问题。

公开快照同时加入页面与导航，站点地图包含干净地址。查询参数和预览页面继续禁止索引。

验证记录：网页检查 405/405 通过，包含数据库不可用时的路由、快照回退、HEAD、索引规则和复制权限被拒绝时的手动选择。浏览器检查了地址复制、客户端配置切换、场景选择与手机菜单；390 和 820 像素宽度下无水平溢出。独立代码审查未发现阻断问题。

接入命令依据 [Codex 文档](https://developers.openai.com/codex/mcp)、[Claude Code 文档](https://code.claude.com/docs/en/mcp)和 [Cursor 文档](https://cursor.com/docs/mcp)，并核对了本机 Codex 的命令帮助。未在这些客户端中修改用户配置或运行付费对话。

部署仍使用原网站 Worker `remoteai-nomads` 的既有配置与密钥，无数据库迁移。上线以生产 `/release.json`、`/healthz` 和实际页面浏览器验收为准；本记录中的本地检查不代替生产验证。
