`npm run check` 不会调用模型。它检查源码语法、数据边界、交互状态、工具参数、预算计算、取消与公开页面快照；真实模型评测需要另行运行并记录发布版本、请求和结果。

没有可靠证据宣称所有体验超过 98 分，也不能把 30 题自动通过率当作真实用户满意度。当前仍需关注模型语义错误、资料时效、真实设备体验，以及 Workers、D1 和模型服务各自的额度。

公开源码发布还会检查：空工作区可重建公开数据；完整页面与数据库对应；密钥和私人导入未进入提交。私有验收原件不随仓库提供，引用它们的历史报告会明确标注这一范围。
