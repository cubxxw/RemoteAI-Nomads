# 国内目的地覆盖与免费数据接入

建议先补全大理、安吉等已收录目的地，再扩充到24个候选目的地。采用官方价格与统计资料、开放地理和气候数据、社区与住宿的直接报价三条采集线。日期、地域和消费方式保持独立，月预算按具体生活方案组合。

本轮完成公开目录审计、源站条款核对和6个小型端点的真实取回，提供可复跑的只读探测脚本。没有向线上D1写入数据，没有发布新城市或改动排名。以下接入和界面调整属于实施建议。

## 当前缺口

审计对象为仓库的2026-10-17公开快照。348个目的地中，中国大陆12个，只有5个具备全部六项旧指标。

| 状态 | 目的地 |
| --- | --- |
| 六项指标完整 | 上海、厦门、成都、杭州、深圳 |
| 六项指标和预算缺失 | 大理、安吉、万宁、昆明、腾冲、泉州、无锡 |

大理和万宁各有12个月的ERA5历史气候，但默认排名要求指标齐全，因此不出现在常规榜单中。安吉还缺坐标和气候。缺指标表达的是资料不足，不能解释为目的地不好，也不能把数据库中的原始0分当成真实评价。

本地城市消费只有上海、深圳各5个CostCompass单项，集中在鞋、健身、整租和汽油。重新取回的CostCompass文件包含北京、广州、上海、深圳四城共20项；北京、广州尚未进入本站目录。上游文件不含大理和安吉，也不开放完整月总价。继续同步同一个源，无法解决这些城市的缺口。

仓库[国内社区名录](../../guides/china-communities.md)还有25条历史线索。它们适合做运营方核查清单，不能直接视为25个正在营业的社区。

## 选哪些来源

| 数据 | 优先来源 | 免费和开放范围 | 接法与用途 |
| --- | --- | --- | --- |
| 地点、别名、上级区域 | [GeoNames下载](https://www.geonames.org/export/)、[Wikidata结构化数据](https://www.wikidata.org/wiki/Wikidata:Licensing) | GeoNames允许商用并要求署名；Wikidata结构化数据CC0 | 离线目录加同国、同省核对，缓存后读取。县、镇、社区分别保留身份。 |
| 买菜、食品价格 | [商务部商务预报的大理州周报](https://cif.mofcom.gov.cn/cif/html/market_scanner/2026/6/1781505968329.html)、[云南商务厅市场监测](https://swt.yn.gov.cn/zfxxgk/fdzdgknr/tjsj/scjc/index.html) | 免费公开网页；按发布者条款引用，不能标为CC许可开放库 | 采集品类、零售/批发、市场类型、元/公斤或元/升、监测周。用于做饭消费参考。 |
| 居民消费、公共服务 | [大理市统计年鉴2024](https://www.yndali.gov.cn/dlsrmzf/c106688/2022493694320480256/5sEBHBLG.pdf)、各地统计局公报 | 免费公开HTML/PDF；开放许可另核 | 年度更新，保留居民人口范围和统计地域。作为当地消费背景，不转成游客住宿报价。 |
| 月份气候 | [Copernicus ERA5月数据](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-single-levels-monthly-means?tab=overview)，地方年鉴作补充 | ERA5数据集列有CC-BY许可；CDS下载需免费账号并接受许可 | 后台批量下载和预计算，同一排名保持相同模型与年份。本地年鉴的单年气象另列。 |
| 气候备用源 | [NASA POWER月度接口](https://power.larc.nasa.gov/docs/services/api/temporal/monthly/) | 免费公开数据服务，实测无需密钥 | 适合覆盖核查和备用；网格地形与当地海拔可能相差明显，不自动替换现有ERA5。 |
| 医院、图书馆、咖啡店等地点 | [OpenStreetMap](https://www.openstreetmap.org/copyright)、[Overpass](https://wiki.openstreetmap.org/wiki/Overpass_API) | 开放数据采用ODbL；公共查询服务有使用限制 | 定期小范围取回、按提供者归属保存。OSM未标注某设施，不表示当地没有。咖啡店也不自动等于可开会工位。 |
| 短租、共居、办公套餐 | 运营方公开页面、主动提交的价目表和有日期的入住经验 | 逐项记录授权；本轮没有核验到统一、覆盖全国的免费开放接口 | 先核大理、安吉、万宁等7城。保留房型、租期、人数、水电和工位包含项，展示可追溯样本。 |

GeoNames中国整包本轮收到HTTP 200，但正文下载超时，未完成ZIP内容校验。Wikidata安吉县JSON已实际取回，国家为中国，名称与县级身份一致；坐标仍是县级位置候选，不是DNA公社或某个房间的位置。

OSM的署名与数据库共享要求按其许可落实，OSM提取记录与其他来源保持归属边界；网站源码的MIT许可不覆盖外部数据。这里只推荐后台采集，浏览器不直接依赖公共Overpass或地名查询服务。

## 大理已有可用的具体样本

大理州商务局2026-06-15发布的周报，监测期为2026-06-01至06-07。实际HTML可取回，只读解析已提取8项，包括大米6.45元/公斤、鸡蛋13元/公斤、牛奶12元/升。超市和农贸市场蔬菜分开保存；原文部分市场在祥云、洱源，归属必须保留为大理州。

这份报告适合验证采集流程，不作为2026年10月现价。正式同步还需发现最新报告，保留旧报告，并单独检查采样期是否过旧。文章的发布时间、监测周和本站读取时间是三种日期。

统计年鉴PDF第28页（书内第15页）明确列出：2024年全体居民人均消费支出30,809元，城镇常住居民33,682元，单位为元/人/年。它反映居民消费结构，不能作为短住者的完整月预算，更不能据此判定2000元在大理一定不够。

NASA接口实际返回大理坐标2023—2025年的36个月、四个气象变量。响应还含3条以13结尾的年度汇总，已在审计中排除；降水单位为mm/day，转换月累计必须按具体年月天数计算。MERRA-2与ERA5不混写为同一模型。源站也[解释了复杂地形中网格海拔与实际地点的差异](https://power.larc.nasa.gov/docs/faqs/data/)。

## 免费服务的选择边界

[CostCompass](https://costcompass.net/data)允许按CC BY 4.0用于商业和AI产品，但其中国覆盖有限；这一条保留作补充。

[Open-Meteo免费服务](https://open-meteo.com/en/terms)限非商业用途，数据的CC BY许可和托管API的免费使用条件分别判断。现有ERA5记录先保留原来源；如要商业化长期更新，优先评估直接从CDS下载，或另行选择符合用途的服务。

[Ookla开放性能地图](https://registry.opendata.aws/speedtest-global-performance/)采用CC BY-NC-SA 4.0，不作为可随意商用的网速底库。城市或网格的网络均值也不能证明实际房间、晚高峰视频会议或特定AI服务的可用性。

[高德的个人免费配额](https://lbs.amap.com/faq/advisory/authorization/43168)有用途条件，不能当成产品永久免费的开放POI库。Meteostat开发者[许可页](https://dev.meteostat.net/license)列出CC BY 4.0，但其[支持页](https://meteostat.net/en/support)仍有CC BY-NC表述；本轮不选为默认源，待具体下载服务和数据许可核对后再接。

小红书、闲鱼、贝壳和点评可供定点核实经验与报价。本轮没有取得可支撑持续批量接入的开放许可和公开接口承诺，因此不把它们设为自动采集主链。

## 数据库怎么接

现有`cost_observations.scope`只允许`city`或`national`，应先解决区域层级。建议新增`geo_areas`与`regional_reference_observations`，将大理州官方菜价、县级公报和国家统计分别关联到真实区域；城市详情通过区域关系读取背景参考。避免把州级资料硬塞进城市观察。

| 记录 | 必须保留的信息 | 使用位置 |
| --- | --- | --- |
| 目的地身份 | 类型、父区域、别名、行政标识、坐标来源与坐标系 | 搜索、地图、县镇与社区归属 |
| 区域参考 | 地域、统计对象、原金额与单位、采样区间、原文位置 | 价格背景和居民消费参考 |
| 住宿报价 | 房型、人数、最短租期、可住月份、水电、押金与其他费用、报价日期 | 合租/独立房间/整租方案；押金与月支出分开 |
| 社区与工位 | 运营方、地址、近期活动、营业核验日、通话与办公权限 | 找社区与工作场所 |
| 网络样本 | 实测或宣传、测量地点与日期、上下行、延迟、测试方法 | 具体办公场景；不从旧10分推成Mbps |
| 用户预算方案 | 住宿选择、餐食方式、交通与办公、必要费用、对应来源ID | AI回答与可编辑费用分项 |

每条观察保留来源、采集时间和内容散列。金额纠正追加记录，不覆盖旧观察。范围或单位不明的记录进入待审区，先不参与预算与排名。已有`cities.budget_*`和`city_scores`保持独立，待新模型和证据验收后迁移。

采集沿用现有Node流程，原始响应放忽略版本控制的缓存；校验和去重后生成待审差异，再批量写D1。Workers只读取已经归一化的数据，不在用户打开页面时抓政府网页或解析PDF。地理目录按月检查，食品周报按其发布周期检查，住宿报价按有效期复核，统计年鉴按年更新；这里只设计周期，没有新增定时任务。

公开数据导出还须同步调整`prepare-release.py`与`bootstrap-public.mjs`的允许表清单，更新城市读取、Agent工具和公开页面快照，再发布。不能只给线上库加新表，却让新安装和故障兜底仍使用旧目录。

## 扩充顺序和网页呈现

先补全已收录的7城：大理、安吉、万宁、昆明、腾冲、泉州、无锡。再核北京、广州已有的开放价格样本；最后调研丽江、景洪、芒市、三亚、文昌、北海、威海、青岛、黟县、德清这10个候选。加上现有12个，共24个目的地候选，尚未作为新城市导入。

候选中含县级与区域型目的地：西双版纳州与景洪分开，黄山与黟县分开，莫干山保留在德清的子区域，不以整个地级市数据代表每个村镇。名单表示采集优先级，尚未证明每个地点都适合当前月份出发。

“国内”视图可以先展示有完整指标的排名，同时在后方保留已有气候或社区证据的目的地，让大理可以被看见和点开。后者暂不展示综合名次；按有证据的月份、消费样本和社区筛选。资料覆盖率与适合程度分开表达。

AI读取结构化观察和出处，按用户选择的房型、做饭方式与办公需求计算方案。2000元预算应触发低价住宿类型和餐食方式的查证；找不到完整证据时给出已知分项、缺口和可调整方案，不能用参考均价直接宣布这座城不可行。

## 可复跑的验证

在`web/`运行，无需密钥或新依赖：

```sh
# 只读审计随仓库提供的公开目录，默认不联网
node scripts/audit-china-coverage.mjs

# 请求6个固定公开端点，响应和散列仅写入本机 .data
node scripts/probe-china-sources.mjs
node scripts/audit-china-coverage.mjs \
  --source-cache .data/china-source-probe \
  --output .data/china-source-probe/audit.json
```

探测覆盖CostCompass两个文件、大理州周报、大理市2024年公报HTML、NASA大理月数据、Wikidata安吉县JSON。本轮6个端点均真实返回200并保存完整正文。年鉴PDF另通过官方文件的全文和指定页核对，未把公报HTML中缺失的消费数值猜出来。

可选的`--include-bulk`才请求GeoNames中国ZIP。下载超时会返回失败状态，不把HTTP 200当成完整数据下载。探测脚本使用固定URL，是接入可行性原型，尚未实现最新周报发现、分页采集、全城覆盖或正式入库。

本机证据为`.data/china-source-probe/requests.json`及`audit.json`；研究原件不随仓库发布。脚本校验已保存响应的散列、国家、来源许可、气象单位和样本月份，输出的数据库写入次数固定为0。

正式入库前，用“州价不能误配古城”“年度消费不能充当月预算”“39条NASA记录只能有36个真实月份”“未实测网络不能生成Mbps”“过期报价不显示为现价”“无旧评分的大理仍能浏览”这些实际问题验收。
