下载后怎么用？

解压后，将完整的 roamorrow-nomad-planner 文件夹放进客户端支持的 Skills 目录，再开启新会话。具体目录以客户端说明为准；安装 Skill 不会自动配置 MCP。

可以与上方 MCP 搭配使用；支持本地 Node.js 22 或更新版本的工具，也可通过包内查询脚本访问同一份公开资料。查看完整说明 ↗

连接后，可以查什么？

按国家或月份筛选候选，比较城市消费样本、历史气候与工作条件，换算会议时间，按明确的费用项目核算预算。

了解数据与方法
这些资料有多新？

每次查询会返回资料来源、日期与缺口。气候资料是历史记录，费用来自不同日期的样本。出发前仍应核实实时天气、住宿报价和官方入境规定。

连接不上，先检查什么？

确认地址以 /mcp 结尾，传输方式为 HTTP，并检查客户端是否支持远程 MCP。浏览器直接打开服务地址并不能验证连接；可用服务健康检查 ↗查看服务状态。遇到请求限流时，稍后再试。

想直接在代码里查询？

也可使用无需登录的 JSON API。参数、原始数据说明与调用示例见开发文档 ↗。公开服务有请求频率与结果数量限制。
