<a id="remote-work"></a>

## 找远程岗位或接单

| 任务 | 入口 | 先看什么 |
|---|---|---|
| 中文岗位、项目与同行交流 | [电鸭](https://eleduck.com/)、[V2EX Jobs](https://www.v2ex.com/go/jobs)、[中文远程工作资源](https://github.com/greatghoul/remote-working) | 岗位发布时间、合同关系与允许工作的地区 |
| 国际职位板 | [Remote OK](https://remoteok.com/)、[We Work Remotely](https://weworkremotely.com/) | “Remote”是否仍限定国家、时区或工作许可 |
| 接单与服务销售 | [Upwork](https://www.upwork.com/)、[Fiverr](https://www.fiverr.com/) | 账户可用性、平台费用和具体付款条件 |
| 找远程友好的公司 | [remoteintech/remote-jobs](https://github.com/remoteintech/remote-jobs)、[awesome-remote-job](https://github.com/lukasz-madon/awesome-remote-job) | 公司名单不是当前招聘承诺，回到企业职位页 |

远程岗位提供工作机会，旅居许可决定能否在目的地开展该工作，两者分别核对。

<a id="stay-and-work"></a>

## 找住房、工位与社区

[Booking](https://www.booking.com/)、[Airbnb](https://www.airbnb.com/)可比较实际日期的短住与月住报价。另查房东近期评价、平台最终账单和取消条款；不要只比较搜索列表里的最低起价。

先看[目的地页](../README.md#全球目的地)里的具体办公入口，再选择通勤方便的住宿。社区规模与活动随季节变，运营方名单不能证明每天有人一起工作。

[The Wired Nomad](https://thewirednomad.com/)用于发现带网络资料的住房；[r/digitalnomad](https://www.reddit.com/r/digitalnomad/)用于搜同季节、同工作类型的体验。两者都需要进一步核对，不能代替房间通话测试。

<a id="money-and-cover"></a>

## 收款与费用

从实际付款方和银行要求倒推工具。[Wise](https://wise.com/)、[Payoneer](https://www.payoneer.com/)、[PayPal](https://www.paypal.com/)、[Airwallex](https://www.airwallex.com/)都是核对入口，支持地区与个人/企业账户限制分别确认；本轮未逐项测算当前费率或中国大陆账户可用性。

人民币结售汇的等值 **5万美元是年度便利化额度，不是全年绝对上限**。超过便利化额度的真实、合法经常项目可按银行要求提供交易材料办理，不需要把“开公司”写成唯一方案。[国家外汇管理局问答](https://www.safe.gov.cn/ningxia/2022/0929/1997.html)

## 保险与国内医保

保险先核居住国与目的地，再读保单的活动、既往症、免赔额和除外责任。下面是产品入口，不给没有年龄和保障条件的统一月价。

| 入口 | 核对方式 |
|---|---|
| [SafetyWing Nomad Insurance](https://safetywing.com/nomad-insurance) | 区分旅行医疗与完整健康保障；网页价格按年龄、方案及附加项变化 |
| [Genki](https://genki.world/) | 看具体计划条款、持续旅居与回国覆盖 |
| [World Nomads](https://www.worldnomads.com/) | 根据居住国、目的地与活动取得适用报价 |

离职或跨地区后，向参保地医保经办机构确认衔接、补缴与等待期。不能把不同地区和不同险种统一写成“断缴三个月年限清零”。[国家医保局：职工医保中断与补缴](https://www.nhsa.gov.cn/art/2025/5/7/art_52_16464.html) · [居民医保参保机制](https://www.nhsa.gov.cn/art/2024/8/1/art_53_13428.html)

## 一套能维持工作的小装备

先带笔记本与合适充电器，确认目的地插座和备用网络。长时间办公再考虑支架、外接键鼠与耳机；便携屏增加重量，按实际任务选择。

重要账户启用多因素认证，保存离线恢复方式；设备与文件备份分开。公共网络上使用 HTTPS 和单位要求的 VPN，VPN 本身不能避免钓鱼、恶意软件或账户泄露。
