# 第一周：住过完整工作日，再决定延长

[返回首页](../README.md) · [目的地](destination-notes.md#destinations) · [预算与时差](destination-notes.md#budget-and-work) · [入境与工作](entry-and-work.md) · [比较与询问模板](choose-a-base.md)

这是一份可复制的行动清单。先填自己的工作底线，每过一关再承诺更长租期；未验证的项目继续标明，不当作通过。5–7 晚是首页建议的试住长度，具体仍按工作安排和可取消的房源决定。

按自己所在阶段开始；每阶段的结果写进同一份记录，方便决定继续、复试或离开。

| 阶段 | 留下什么结果 |
|---|---|
| [订房前](#订房前) | 工作底线、完整报价、取消截止时间与替代方案 |
| [到达试住](#到达试住) | 房间与设施是否一致，网络、噪音与通勤初测 |
| [完整工作日](#完整工作日) | 正常班次的实测记录，区分通过、未通过与未验证 |
| [决定延长](#决定延长) | 延长后的总消费、权限与退出条件 |
| [失败后怎么选](#失败后怎么选) | 换房、换工位、复试或离开的下一步 |

## 订房前

先复制一行底线，后面的“通过”都对照它判断，而不是只看测速数字：

> 试住日期 ___；当地工作时段 ___；必须完成的会议/任务 ___；安静与保密要求 ___；总消费上限 ___；可承担的退出成本 ___；最晚取消/决定时间 ___。

- [ ] 写下当地工作与会议时段、必需工具、安静通话需求和可接受通勤。用实际日期换算时区，夜班先问门禁。
- [ ] 核实自己的入境与工作条件，以及雇主跨境办公要求；不确定时先回[手续页](entry-and-work.md)，不要靠住宿承诺判断资格。
- [ ] 用[房东与工位模板](choose-a-base.md#发给房东与工位的询问模板)拿到实际房型、总价、房间测速、通话空间、夜间权限和备用方案的答复。
- [ ] 填[同口径比较卡](choose-a-base.md#用实际月份比较费用)：房租与工位分开，消费与可退押金分开，未知项不填零。
- [ ] 保存订单、取消截止时间、扣费与退押金条件；选好一个可询价的替代住处或工位，预留换房和回程资金。

**这一关没过：** 关键费用或取消条件不清，就先问清；实际工作时段没有可用空间，继续比较其他房源或工位。对方不能提供测速可记未知，但不要因此直接预付不可退的整月费用。短住仍要有可承担的退出成本。

## 到达试住

- [ ] 确认拿到的房间与报价一致，拍下桌椅、设施和已有损坏；发现差异尽早通过约定渠道反馈。
- [ ] 在实际工作房间试网络与手机热点，按自己的需求核流量限制。记录测试日期、时段和使用的网络。
- [ ] 白天、夜间各观察一次噪音；试桌椅、照明和温度能否支撑工作与休息。
- [ ] 走一遍住所、吃饭、超市和工位的路线。按真实班次检查交通，尤其是深夜会议结束后的回程。
- [ ] 买一天工位或确认可试用安排，问清通话间预约、额外费用和日票权限。

**这一关没过：** 房间噪音、设施或实际房型影响工作，先要求可核实的调整；调整后再试。若问题仍在，按订单条款评估换房。通勤或夜间回程不可接受，就换更近的住处或工位，不急着办月票。

## 完整工作日

选择有代表性的工作日，覆盖平常的会议与专注时段；夜班按夜班试。先把试验排在取消或续住决定截止前，留出调整和复试时间；做不到时，把未测试条件与可能损失写进决定，不当作通过。一天只能证明这次表现，长住仍需保留备用方案。

- [ ] 在计划长期办公的位置坐完自己的正常班次，使用公司要求的网络方式、常用服务和工作工具。
- [ ] 用真实会议工具完成通话，观察上传、延迟、卡顿、掉线和背景噪音；保密会议按单位要求选择空间。
- [ ] 在不影响工作与他人的前提下，试一次从主网络切到手机热点，确认能否继续任务。不能实测备电时，记“仅运营方答复，未验证”。
- [ ] 实际使用通话间，核实预约能否覆盖会议长度；确认加班、周末或夜间的进出权限。
- [ ] 记下桌椅、通勤和作息是否可持续，补齐当天账单与未计费用。

复制这几行留下结果：

> 日期 / 当地工作时段 / 位置：___。
>
> 用了哪些工具、开了多长会议：___。
>
> 主网络表现 / 热点切换 / 通话空间：___。
>
> 已验证通过 ___；未通过 ___；仍未验证 ___。
>
> 调整方案 ___；何时复试 ___；最晚作决定的日期、时间及时区 ___。
>
> 必须满足的底线是否全部通过 ___；未验证项的替代方案、可用证据与额外消费 ___。

**这一关没过：** 主网络不稳，先试已确认可用的备用网或其他工位；房间能休息但不适合通话，可比较“住处 + 独立工位”的总消费。调整后仍不能完成必要任务，就换房、换工作地点或缩短停留，不用整月预付款赌它会改善。

## 决定延长

把实测结果和新报价一起判断：短住通过只证明测试时的条件，延长后换房、换工位或换班次都需要重新核对受影响的项目。

- [ ] 工作底线已通过实际验证；备用条件仍未验证时，已写明可接受、可承担的替代方案及其依据；必需的工作条件未通过时，先调整复试。
- [ ] 复算首周实际消费，补上通话间、通勤、水电、清洁和平台费；比较长租后的总消费与现金占用。
- [ ] 拿到延长日期、同一房间或替换房型、工位权限的书面确认；短住可用不代表月租包含同样服务。
- [ ] 再核月租取消、提前离开、押金扣除和退还时间，保留订单与对话记录。
- [ ] 确认停留安排仍符合个人手续与雇主要求，决定延长 ___ 晚，或在 ___ 日离开。

**这一关没过：** 有关键未知就暂不承诺整月；若短租费用与风险可接受，可延长几晚复试。预算、班次或可用空间持续不合适，就缩短停留或重选目的地。

## 失败后怎么选

决定前写一行：**触发退出的条件 ___；替代住处或工位及已确认条件 ___；换房/离开日期 ___；预计损失与待退押金 ___。** 仍没有可用替代方案时，不把“到时再找”记成已有保障。

- **只有房间不合适：** 保留已验证可用的工位，先比较附近可试住的替代房源。
- **只有工位不合适：** 房间能休息就先保留，试另一个工位或符合工作要求的房内方案；把额外通勤与通话费算进去。
- **作息、预算或两处都不合适：** 比较调整后的实际消费与搬走成本，考虑缩短停留或换城；不要让已发生的短住消费决定继续加钱。
- **截止时间快到：** 按已保存的取消条款处理，记录损失与退还款；未完成的验证继续写明，不把它包装成长住推荐。
