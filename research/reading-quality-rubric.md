# 阅读质量评分标准 v1

[旅居指南](../guides/destination-notes.md) · [项目首页](../README.md) · [比较与试住](../guides/choose-a-base.md)

本标准的“首页”指[目的地笔记](../guides/destination-notes.md)这一指南入口及其专题路径；项目 README 的网站排行与生成表格另按网站流程维护。本次只明确评估对象的迁移位置，20项条件与权重不变，历史分数不自动转为迁移版本的验收结果。

本标准用于维护指南的阅读体验，不给城市打分。固定为 20 项、每项 5 分，总分 100；连续迭代不改变权重。全部满足得 5 分，部分满足且明确写出缺口得 2 分，不满足得 0 分。未完成验证写“未验证”，不得按通过计分。

这是编辑审查与任务走查，不是真实用户研究，也不能用检查通过比例代替满意度。自动检查只提供结构证据；语义、决策是否清楚、窄屏真实可读性仍需人工或浏览器验证。每项记录定位、操作与缺口，不以“感觉更美”代替证据。

| 编号 | 维度 | 得 5 分的条件 |
|---|---|---|

## 评估步骤

1. 修改前先固定快照，按 20 项评分并列出失败任务。
2. 第一轮改阅读路径和内容；第二轮按同表复评后修最影响决策的缺口。
3. 最后一轮实际点击关键入口、在桌面与 390px 窄屏检查，并复跑自动检查。
4. 将每项分数、证据、每轮变更与未验证项写进迭代记录。达到目标仍保留缺口；不为追分删掉重要条件或另改评分标准。

目标为 90 分以上且无关键误导。低于目标就解释残留问题和阻碍；不得事后抬分。自动检查不计入人工总分，也不为凑分设置强制文案或固定段落长度。

## 可复核的人工走查协议（v1 权重不变）

分数是编辑自评，不代表用户满意度、成功率或城市品质。每项沿用 5 / 2 / 0；未实际验证记 `U`，总分按 0 贡献并另报覆盖率（例如“已验证 18/20，保守总分 84/100”），禁止把分母缩成已验证项后换算百分制。2 分必须说明已完成哪部分、剩余缺口及影响。自动脚本通过不能给任何人工项直接加分。

固定以下任务与起点，用同一份情境比较迭代前后。走查记录应包括版本/日期、操作者、视口、入口、实际点击路径、读者需作出的判断、结果与卡点。时间和点击数可作观察，不设置“越少越好”的分数；来源与重要限制需要的阅读不能为了提速删掉。

| 任务 | 起点与情境 | 完成的可观察结果 | 主要评分项 |
|---|---|---|---|
| 缩小候选 | 首页；需覆盖北京时间工作、每周多次视频会、不骑车 | 选出两个待试住候选，说明各自代价与仍需询问的事项；无法排除时能指出缺少什么 | N1–N3、D1、D3 |
| 比较费用 | 首页；同一人、同日期、同房型、30晚 | 找到比较模板，区分押金/消费、个案/均价、无报价/免费；保留不可比项 | N2、D2、E2、E3、A1 |
| 核读证据 | 任意城市卡；追查一项价格和一项风险 | 说明何时发表/何时核读、材料支持到哪一步、当前状态仍待确认之处；缺来源记失败 | S4、E1–E4 |
| 准备试住 | 首页；已选候选，尚未付款 | 找到手续与雇主核对、订房前询问、首周试验和延长/退出条件 | N4、D4、A1、A2 |
| 窄屏完成路径 | 390px；重复上述至少一条完整路径并打开一张城市卡 | 入口可点、能回主路径；正文不横向溢出，表格可局部滚动；限制和证据名称仍可辨 | A3、A4 |

认知负担要记录具体障碍：是否反复往返才懂一个概念、是否需记住上一页多项条件、同一概念是否换名、行动与背景是否混排、未知值是否诱导读者自行猜测。标题/标签存在或段落短只能作为定位证据；不能据此断言“容易理解”。层级审查需说明先看到什么、关键限制在决定前是否可见；不得只统计标题数量或关键词。

A3/A4 的满分需真实浏览器记录：桌面与 390px、页面或渲染方式、具体入口和表格、溢出与链接检查结果。Markdown 源码审查不能替代窄屏或辅助技术验证。只查标题和表头不能声称已通过屏幕阅读器测试。

## 自动检查契约与边界

`python3 scripts/check_reading.py --guide guides/destination-notes.md` 以目的地笔记为指南入口，检查到固定任务目标的本地路径、专题回指南入口、城市唯一显式锚点与城市入口，以及卡片到所属 `source_ids` 至少一个来源的直接或一次本地 Markdown 中转路径。代码块、行内代码、HTML 注释和图片本身不构成入口；包裹图片的外层链接可以构成入口。来源中转锚点限定到对应小节，后续城市不能代替前一张卡提供来源。

这只是有界 Markdown 的结构检查：不抓取外站，不核价格/法规/时效，不判断链接文字是否清楚或来源是否支持具体断言；未模拟 CSS、折叠、隐藏内容或浏览器可点击性。不支持的 Markdown/HTML 写法应人工检查或配套链接检查。风险/费用词汇仅产生人工复核提醒：出现词汇不能证明内容完整，未出现也不证明内容缺失。脚本不输出体验分数。

出现会误导付款、合法办公判断或费用比较的关键问题，即使总分达到90仍不能宣称达标。报告保留原始分数、验证覆盖和阻断项；修复后按相同任务复查，不更改权重追分。

## 本轮复评的证据约束

由 agent 完成的任务走查统一称“人工代理评估”，不是用户测试，也不能称为用户成功率。内容编辑者、审查代理和自动脚本的结论应分别归属；同一系统中的另一代理不构成外部独立研究。

复评必须读取当前稳定版本并重记20项，不能把历史满分直接平移。证据列区分：源码语义走查、来源记录抽查、外部原文重新核读、实际浏览器点击；未做的层次明确写出。E2 的“每个费用观察”需要逐条对应币种、范围、时间与来源，抽样只能支持部分完成（2分），不得把链接存在当作全面复核。A3/A4 未取得实际浏览器结果记 U，保守总分按0；完成的源码内容项也不表述成可用性测试通过。

来源中转的重复显式锚点属于歧义入口，阅读脚本不将它算作有效证据路径。该检查发现结构歧义，不能决定浏览器最后滚动到哪个重复元素。
